UUID產生器

依 RFC 9562（取代 RFC 4122）產生標準 UUID：支援 v4 隨機、v7 時間排序、v1／v6 時間型、v3／v5 命名空間雜湊，以及 Nil／Max。可批次產生、轉換格式，也能貼上任何 UUID 解析版本、變體與時間。所有運算都在你的瀏覽器內完成。

03該選哪個版本？

v4最通用的隨機 UUID（122 位隨機）。資料庫主鍵若量很大，隨機順序會讓索引較分散。
v7前 48 位是 Unix 毫秒時間，之後隨機：可依產生時間排序，對資料庫索引友善，新系統的首選。
v1 / v6時間戳（100 奈秒）+ 節點。這裡的節點是隨機產生，不會洩漏網卡 MAC；v6 把時間欄位重排以便排序。
v3 / v5由「命名空間 + 名稱」決定，結果固定可重現。v5 用 SHA-1，v3 用 MD5，新用途建議 v5。
Nil / Max全 0 與全 f 的特殊值，常用來表示「空值」或「上限」。
