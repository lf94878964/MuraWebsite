# 補簽系統與補簽券
## 補簽使用
每次補簽需要消耗一張【🎟️補簽券】，若沒有【補簽券】則花費柚子幣資產。
補簽到後，計入連續簽到日期與累計簽到日期。
:::warning 注意！
補簽到後**不會補發補簽日期的獎勵**。
補簽到最多可以補簽 30 日前。
:::

## 無【🎟️補簽券】的補簽貨幣花費公式
花費貨幣資產的金額公式如下：
定義以下參數：
```
N 為 第 N 次補簽到
A 為補簽後擬連續天數
D 為貨幣折扣係數

D的公式： 1.045 − 簽到等級 × 0.045 （最低 0.2 ）
```
必須同時滿足：
- 傻幣：N
- 柚子幣：500 × N × A × D
必須同時有足夠的傻幣與柚子幣才可簽到。
