# 電子口（禁）球（言）
### 指令列表
>- **/電子口球**

### 【/電子口球】說明
>這是一個娛樂性指令，可以輸入指令讓自己被禁言（以批踢踢的話來講就是自請水桶），或著邀請他人被禁言（建立在於雙方都同意的情況下）。
>除了可以自我戴上，亦可邀請他人戴上電子口球，只要對方同意則對方也會被戴上電子口（禁）球（言），只不過有機會吃到反噬...連自己也被戴上...?
>- 【time】：禁言秒數，必填，上限與下限受到伺服器關於電子口球設定值【max_time】與【min_time】值影響。
>- [who]：為指定對象，選填，有填寫此欄為邀請模式，否則為自請模式。

#### 自請模式
>輸入後，機器人會在當前頻道公開詢問是否接受：
>![image](https://hackmd.io/_uploads/HJYxIgChxe.png)
>坦若同意，點「我同意」按鈕，反之亦然。點同意後立即執行禁言：
>![image](https://hackmd.io/_uploads/rJKVLgRhgg.png)
>![image](https://hackmd.io/_uploads/rJ9BLxR2xl.png)
>⚠️：基於Discord設定，具有管理權限者無法被禁言，若指令輸入者具有管理權限此指令無法運行。

#### 邀請模式
>輸入後，機器人會先向你傳送警告訊息：
>![image](https://hackmd.io/_uploads/rk19Ue02xx.png)
>其中反噬機率與反噬倍率由伺服器管理設定值決定（設定部分詳見電子口球管理設定）
>點擊【我同意】後在當前頻道標註被邀請者及相關訊息：
>![image](https://hackmd.io/_uploads/HkhWPlA2xl.png)
>被邀請者點【我同意】後立即執行禁言，同時啟動反噬檢測。
>![image](https://hackmd.io/_uploads/rJy8Ol0ngx.png)
>⚠️：基於Discord設定，具有管理權限者無法被禁言，若邀請對象者具有管理權限此指令無法運行。

:::Warning 反噬檢測
反噬檢測啟動後，先行檢查是否符合以下三個條件任一：
- 伺服器反噬機率設為0%
- 伺服器反噬倍率設為0倍
- 邀請者具有管理權限

符合以上任一，**反噬必定不會觸發**，若不符合依照機率決定是否觸發反噬。

反噬觸發後，邀請者也會受到禁言，秒數為`輸入的秒數 * 反噬倍率`，並且公頻的訊息會跳出吃到反噬的幸運兒。
![image](https://hackmd.io/_uploads/HkFNOeA2el.png)
:::
