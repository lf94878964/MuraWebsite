# 千恋＊万花機器人補償規則
> - 制定日期：` 2026 年 05 月 15 日 `
> - 政策版本：` 26.1 `（修正日期：無）

### 第一條、補償條件
符合以下情況任一者，均可申請補償：
- 因機器人Bug導致被損失財產
- 因機器人重啟導致被損失財產

第二項重啟若為定時重啟或已發布公告的排定重啟或維護則不在此限。
損失財產定義包含但不限於：金錢損失、DCTW特權授予損失等。
補償不得以現實金錢或其他在現實中具有金錢價值聲討補償。

### 第二條、補償發放

| 補償種類 | 補償發放 | 補償對象 |
|:---:|:---:|:---:|
| 3小時以內機器人非預期停機 | 不予補償 | - |
| 3小時以上機器人非預期停機 | 柚子幣 10000元（含）以上且應發放補簽卡 | 全部人 |
| 12小時以上機器人非預期停機 | 柚子幣 30000元（含）以上且應發放補簽卡 × 影響天數 | 全部人 |
| 已發布公告且停機時間大於 3 小時以上 | 公告決定補償內容 | 全部人 |
| 賭博遊戲進行到一半按鈕或程式卡住 | 補償該局本金 | 受影響者 |
| 賭博遊戲進行到一半按鈕或程式卡住，並且依據客觀條件判定獲勝機率大於 90% 者 | 視情況補償該局獲勝之獎勵 | 受影響者 |
| 賭博遊戲進行到結束按鈕或程式卡住，並且確定該局獲勝且未發放獎勵者 | 補償該局獲勝之獎勵 | 受影響者 |
| 賭博遊戲客觀下可歸咎於當事人操作的行為 | 不予補償 | - |
| 賭博遊戲客觀下可歸咎於 Discord API 者 | 視情況補償 | 受影響者 |
| 賭博21點勝負已定但驗牌按鈕失效 | 不予補償 | - |
| 賭博21點驗牌局按鈕或程式卡住 | 不予補償 | - |
| 任何無押注本金的小遊戲按鈕或程式卡住 | 不予補償 | - |
| DCTW投票獎勵未發放 | 補償該獎勵 | 受影響者 |

本條本金包含但不限於：一開始下注的金額及中途追加的金額
如有本表未列出但應補償的規則，由開發者認定並作解釋，同時形成的補償先例規則與解釋與本規則具有同等效果。
本表得隨時新增或修改，不須公告通知。
補償發放最終解釋權為開發者所有。

### 第三條、補償申請期限
補償申請期限為：
- 知悉遭受損失起三小時內申請 且
- 該損失產生後的三天內申請

否則不予補償

### 第四條、補償申請
補償一律至 [支援群](https://discord.gg/nNn8GsF5bA) 的 [🆘．補償專區](https://discord.com/channels/1378966069456408657/1496467977212661800) 頻道發送相關證據，以其他方式申請補償的一律駁回。
