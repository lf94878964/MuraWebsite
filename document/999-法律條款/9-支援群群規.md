# 機器人支援群群組規則

:::success
歡迎加入[千恋＊万花機器人支援群](https://discord.gg/nNn8GsF5bA)，請詳細閱讀以下規則：
:::

## 基本原則
- **A. 請尊重他人**：禁止 `人身攻擊、恐嚇、誹謗、仇恨、騷擾、侮辱、欺騙、歧視` 或任何基於惡意的行為 ，請以善意且尊重地對待他人。
  - 若是對於機器人以及開發團隊行人身攻擊、恐嚇、騷擾或任何基於惡意的行為，必定永久停權。
  - 機器人事務一律至[💼．票務開單](https://discord.com/channels/1378966069456408657/1442072577886654637)開單說明，切勿私訊開發團隊成員，保留團隊成員隱私空間
  :::danger
  違者處禁言一天以上～永久停權，並刪除違規訊息
  :::
  
- **B. 請正確使用頻道**：請在正確頻道使用指令（包含前綴指令）。
  - **允許指令的頻道**：【指令Ciallo～(∠・ω< )⌒☆】類別下的所有頻道
  - **允許簽到的頻道**：[#🍩．快速簽到](https://discord.com/channels/1378966069456408657/1470820843729981628) 與【指令Ciallo～(∠・ω< )⌒☆】類別下的所有頻道
  - **申請一般性補償**：一律至 [#🆘．補償專區](https://discord.com/channels/1378966069456408657/1496467977212661800) ，請先詳閱 [補償規則](https://murasamebot.com/docs/999-%E6%B3%95%E5%BE%8B%E6%A2%9D%E6%AC%BE/8-%E8%A3%9C%E5%84%9F%E8%A6%8F%E5%89%87)。
  - **漏洞回報／申訴案件／合作申請**：一律至[💼．票務開單](https://discord.com/channels/1378966069456408657/1442072577886654637)開單或使用 `/report` 回報。
  :::danger
  違者處禁言一小時～一天；累犯者得永久停權，並刪除違規訊息
  :::
  
- **C. 禁止談不適當話題**：禁止不適合全年齡層的內容發送至頻道上，以下特例除外：
  - **分享色情圖片／視覺小說 H 場景**：一律至[#🔞．限制場景](https://discord.com/channels/1378966069456408657/1379049617290694697)頻道發送，且**嚴格禁止「蘿莉」、「正太」、「獵奇或引人不適」的圖片或對話**
  - **視覺小說遊戲內暴雷對話或討論**：一律至[#🥭．視覺小說討論](https://discord.com/channels/1378966069456408657/1566818863088275517)討論，~~當然包含蔚Ｏ檔案為師與學生們的對話~~
  - 除此之外，禁止於任何頻道發表包含但不限於 `裸露、血腥、未成年、蘿莉、正太、獵奇或引人不適、種族歧視、性別歧視、過當政治話題` 等不適當對話
  :::danger
  違者處禁言一小時～永久停權，並刪除違規訊息
  :::
  
- **D. 禁止未受批准的宣傳行為**：禁止在任何頻道以任何方式做宣傳，包含私訊宣傳也是禁止的，以下情況除外：
  - 允許在用戶個人資料中置入其他群組或頻道連結，但若認定為引誘他人點擊者，依然處分
  - 合作夥伴於[#⚡．合作社群](https://discord.com/channels/1378966069456408657/1379069139158569070)、使用 `/合作伺服器` 指令或經開發團隊批准的宣傳者不在此限
  :::danger
  違者處禁言一天～永久停權，並刪除違規訊息
  :::
  
- **E. 禁止洗頻或發送大面積佔版訊息行為**
  :::danger
  由機器人判定，違者處禁言一天～永久停權，並刪除違規訊息。若洗頻目的為快速達到活動資格者，取消其活動的資格。
  :::
  
- **F. 禁止濫用客服單**：於[💼．票務開單](https://discord.com/channels/1378966069456408657/1442072577886654637)開單後十分鐘未回應，或誤觸開單按鈕未立即告知開錯者就關單，視為濫用客服單行為，一律停權處理。
  :::danger
  違者處永久停權。
  :::
  
- **G. 禁止在[🍭．甜蜜蜜罐](https://discord.com/channels/1378966069456408657/1402221235621990400)發言**：這是偵測被盜帳號的頻道，於此頻道發言一律永久停權，包含做死的。
  :::danger
  違者處永久停權。
  :::
  
- **H. 請遵守 [Discord TOS](https://discord.com/terms) 有關規定**，包含：
  - 禁止未滿十三歲狀態下使用 Discord 等

### 附則
- 處分種類包含：永久停權、踢出、禁言、警告。
- 警告次數與機器人警告共用，**滿兩次者處永久停權**。
- 於支援群遭處分永久停權者，依據[使用與遊玩守則](https://murasamebot.com/docs/999-%E6%B3%95%E5%BE%8B%E6%A2%9D%E6%AC%BE/3-%E4%BD%BF%E7%94%A8%E8%88%87%E9%81%8A%E7%8E%A9%E5%AE%88%E5%89%87)規定，亦處分機器人使用權停權。
- 開發團隊保有最終解釋權。
- 加入支援群即代表您同意本群規、[使用與遊玩守則](https://murasamebot.com/docs/999-%E6%B3%95%E5%BE%8B%E6%A2%9D%E6%AC%BE/3-%E4%BD%BF%E7%94%A8%E8%88%87%E9%81%8A%E7%8E%A9%E5%AE%88%E5%89%87)與本機器人有關政策。

## 機器人遊玩規範
:::warning
### 詳細規則請見[千恋＊万花機器人使用與遊玩守則](https://murasamebot.com/docs/999-%E6%B3%95%E5%BE%8B%E6%A2%9D%E6%AC%BE/3-%E4%BD%BF%E7%94%A8%E8%88%87%E9%81%8A%E7%8E%A9%E5%AE%88%E5%89%87)，以下僅為摘要：
:::
### 1.禁止對本機器人做出不利於發展之行為
- 違反法律、Discord TOS／開發者政策，或使機器人受到平台處分
- 濫用、破壞、盜用機器人，竊取 Token 或資料
- 發現重大漏洞卻不通報，或利用漏洞牟利
- 未經同意抄襲、借鑑開發團隊的條款、文案，或反編譯、逆向工程
- 🔨 處分：10年～永久停權（漏洞類為 3天～永久）

### 2. 禁止不當經濟行為
- **禁止遊戲外交易（RMT）**：包含現金、私訊交易，連口頭開玩笑也算，交易雙方皆受罰，不得申訴
- **禁止多重帳號**：經濟系統終身僅限一個帳號，小帳與主帳一併處分
- **禁止不公平資源集中**：長期、大量、單向轉移資源給特定帳號
- **禁止自動化**：SelfBot、連點器、自動農場工具
- **轉帳備註禁止不當字詞**：交易無效、金額沒收
- 🔨 處分：停權（最重永久）、沒收資產，得併科罰款 10%～100% 財產

### 3. 禁止濫用投稿與回報
- `/語錄申請`：禁止重複或高度相似投稿、被否決後再投、投稿 H scene 畫面、洗後台、投稿與視覺小說無關內容
- `/report`：禁止無意義文字、故意與類型不符、洗後台
- 🔨 處分：7天～永久停權，不得申訴

### 4. 特殊行為
- **支援群違規**：鬧事、違反群規被停權者加入、觸發盜帳偵測
- **惡意攻擊機器人**／開發團隊：騷擾、辱罵、造謠、頻繁或惡意私訊機器人、炸群刷後台
- **欺騙開發團隊**：申訴或補償提交假證據、逾期不繳罰款
- **規避懲處**：被停權者用小帳繼續遊玩，主帳停權延長至永久
- **惡意催更**：重複催促、威脅或勒索開發者（1天～永久停權，或警告）
- 🔨 處分：多為 7天～永久停權；規避懲處為 10年～永久

### 5. 處罰與申訴
- 處罰類型：停權、經濟系統停權、沒收資產、罰款、警告（滿 2 次即停權）、清空紀錄
- 處分後 3 年內再犯者加重處罰
- 申訴請至 [💼．票務開單](https://discord.com/channels/1378966069456408657/1442072577886654637)，須於處分後 14 日內提出
- 以下情形不可申訴：第 1.1、1.3.1、1.3.2、3.1、3.2、4.1.1、4.1.2、4.2（不含 4.2.4）、4.3 條，以及有明確證據的 RMT 行為
- 經濟類處分（2.1～2.3）舉證責任在申訴人
- 「我不知道規定」「是我兄弟姐妹」「帳號被盜」「花了很多錢」等理由不被接受
