# 機器人運行狀態監控 (Bot Stats API)
~~但某方面來說不太算是一個API~~
## 1. 基本資訊
- URL：`https://murasame-5c56a-default-rtdb.firebaseio.com/`
- 數據格式：` JSON `
- 認證方式：` 無 `
- 通訊協定：` HTTPS (GET/PUT/PATCH) `

## 2. 端點說明
### 獲取機器人完整統計數據
獲取當前機器人所有運行的統計資訊。
- URL：`/bot_stats.json`
- 方法：` GET `

## 3. 欄位定義

| 欄位名稱 | 類型 | 說明 |
| :--------: | :--------: | :-------- |
| backup | Integer | 備份編碼（第幾次備份） |
| backup_version | String | 備份版本碼 |
| ban_servers | Integer | 黑名單的伺服器數量 |
| ban_users | Integer | 停止機器人使用權的用戶數量 |
| bot_avatar | String | 機器人頭像 Discord CDN 網址 |
| bot_id | Float | 機器人唯一識別碼|
| bot_name | String | 機器人名稱 |
| command | Integer | 指令使用總次數 |
| command_count | Integer | 機器人現有的指令總數 |
| guilds | Integer | 伺服器總數量 |
| last_update | Float | 最後一次數據更新的時間戳 |
| restart | Integer | 機器人累計重啟次數 |
| shard_info | Integer | 分片總數 |
| silly_burned | Integer | 傻幣回收總量 |
| silly_circulation | Integer | 傻幣當前流通量 |
| silly_issued | Integer | 傻幣發行總量 |
| start_time | Long | 本次運行的啟動時間戳 |
| status | String | 機器人當前在線狀態 |
| total_quotes | Integer | 語錄系統儲存的總數 |
| user_guild | Integer | 所有伺服器成員累計總數 |
| user_install | Integer | 個人安裝(User Apps)的數量 |
| user_total | Integer | 使用者總數 |
| version | String | 機器人程式版本號 |
| yuzu_burned | Long | 柚子幣回收總量 |
| yuzu_circulation | Long | 柚子幣當前流通量 |
| yuzu_issued | Long | 柚子幣發行總量 |

## 4.範例請求
### 使用 cURL
```bash
curl -X GET "https://murasame-5c56a-default-rtdb.firebaseio.com/bot_stats.json"
```
### 使用 JavaScript (Fetch API)
```js
fetch('https://murasame-5c56a-default-rtdb.firebaseio.com/bot_stats.json')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error('Error:', error));
```
## 5. 狀態碼說明
| 狀態碼 | 描述 | 解決方案 |
| :--------: | :--------: | :-------- |
| 200 OK | 請求成功 | 正常回傳機器人統計數據。 |
| 401 Unauthorized | 權限不足 | 請檢查 Firebase Database Rules 是否允許讀取。 |
| 404 Not Found | 路徑錯誤 | 請確認 /bot_stats.json 節點路徑是否正確。 |
| 403 Forbidden | 禁止訪問 | 請求被 Firebase 安全規則拒絕。 |
| 500 Internal Error | 伺服器錯誤 | Firebase 服務端暫時性異常。 |
