# 千恋＊万花機器人使用與遊玩守則

- 生效日期：` 2026年05月01日 `
- 修正日期：` 2026年10月04日 `
- 政策版本：` 26.2 `


## 序言
感謝您使用「千恋＊万花機器人」（以下簡稱本機器人）。本機器人致力於將視覺小說的魅力與 Discord 社群互動結合，提供包含角色互動、語錄蒐集及虛擬經濟開發等多樣化功能。
鑑於經濟系統的公平性為本機器人發展之核心，任何破壞平衡的行為均將損害全體使用者的體驗。為了維護一個公平、友善且永續的遊玩環境，並保障開發團隊的智慧財產權與整體社群利益，特制定本《千恋＊万花機器人使用與遊玩守則》（以下簡稱本守則）。
本守則特別針對虛擬經濟行為規範（如：多重帳號、非法交易、自動化濫用等）訂定嚴格之處分準則。 當您開始使用本機器人、參與經濟系統、轉帳或投稿內容時，即代表您已充分閱讀、理解並同意接受本守則之所有約束。
請使用者務必恪守規範，共同維護這個屬於大家的虛擬家園。在您展開這段旅程前，請詳閱以下條款。
## 第一條、禁止對本機器人做出不利於發展之行為
:::danger
違反以下規則時，即觸犯本條規定，違者必定 **機器人使用權停權** 處理。
:::

### 1.1：總則
- 1.1.1：（試圖）利用機器人做違反法律、Discord TOS、Discord 開發者政策等規範；
- 1.1.2：（試圖）使本機器人受到Discord官方處分者；
- 1.1.3：（試圖）使本機器人受到非Discord官方但為本機器人宣傳平台（例如：DCTW）處分者；
- 1.1.4：（試圖）濫用、破壞、盜用機器人、竊取Token、竊取機器人資料；

:::danger
停權期限：10年～永久。
:::
### 1.2：漏洞通報義務
- 1.2.1：發現機器人服務之重大漏洞而知情不通報者；
- 1.2.2：利用漏洞牟取不當利益者；

:::danger
停權期限：3天～永久。
:::
### 1.3：尊重智慧財產權
- 1.3.1：未經開發團隊同意，參考、借鑑或抄襲開發團隊所屬服務條款、機器人服務或文案者；
- 1.3.2：未經開發團隊同意，（試圖）反編譯或逆向工程機器人的 API 或程式行為者；
- 1.3.3：其他侵害機器人智慧財產權之行為人；
- 1.3.4：經合作方通知或公告，有參考、借鑑或抄襲合作方之文案、排版或機器人，而嚴重損害合作方智慧財產權利者；

:::danger
停權期限：10年～永久。
:::

- 1.1.1條的Discord TOS：包含 [Discord服務條款](https://discord.com/terms) 、 [Discord社群守則](https://discord.com/guidelines)。

- 1.3.1條的文案：包含但不限於機器人宣傳文、支援群公告或介紹之文章等

## 第二條、禁止不當經濟行為
:::danger
違反以下規則時，即觸犯本條規定，違者得處 **機器人使用權停權** 、**罰款**、**警告**等。
若涉及到小帳、交易雙方等，一併適用。
:::
###  2.1：禁止一切形式的遊戲外交易（ＲＭＴ）
  - 2.1.1：經檢舉或主動調查（系統異常偵測等亦同），發現存在於遊戲外交易（包含但不限於：口頭開玩笑的、私訊交易、現金交易等），處機器人使用權停權並沒收所有資產。
  - 2.1.2：本條適用於交易雙方或提出交易者。
  - 2.1.3：經明確證據指出有遊戲外交易者，不得申訴。
  - 2.1.4：觸犯本條者開發團隊沒有補償義務。

:::danger
停權期限：10年～永久。
:::
### 2.2：禁止多重帳號遊玩經濟系統
  - 2.2.1：每位玩家遊玩本機器人經濟系統**終身僅限擁有一個帳號**。任何形式的操作分身帳號（小帳）遊玩經濟系統均嚴格禁止。
  - 2.2.2：違者主帳連同小帳處機器人使用權停權並沒收所有資產。
  - 2.2.3：經開發團隊合理懷疑行為人疑似觸犯本款規定者，亦同。
  - 2.2.4：非經濟系統的指令不受本款規定限制。

:::danger
停權期限：3天～永久 得併科罰款自身財產 10%～100% 或指定金額。
:::
### 2.3：禁止不公平的資源集中
  - 2.3.1：禁止透過任何非公平交易的手段，將經濟系統之資源（貨幣等）單向且不對等地集中於特定帳號，包含以下範例：
    - 以各種名義長期、大量、單向無償的資源轉移於特定帳號等
    - 創建或利用任何小帳獲取資源，再將其轉移給主帳號。（同時違反2.2款規定）
  - 2.3.2：違者操作者與特定帳號處機器人使用權停權並沒收所有資產。

:::danger
停權期限：3天～永久 得併科罰款自身財產 10%～100% 或指定金額。
:::
### 2.4：禁止自動化濫用或使用SelfBot操作
  - 2.4.1：嚴禁使用自動機器人（SelfBot）、連點器、自動農場工具或任何其他自動化遊戲方式。
  - 2.4.2：違者依情節輕重處經濟系統停權或機器人使用權停權，並沒收所有資產。

:::danger
停權期限：14天～永久 得併科罰款自身財產 10%～100% 或指定金額。
:::
### 2.5：轉帳指令備註禁止輸入不當字詞
  - 2.5.1：違者該轉帳交易無效，其金額強制沒收。
  - 2.5.2：且轉帳人依情節輕重處經濟系統停權或機器人使用權停權，並沒收所有資產。

:::danger
停權期限：1天～永久 得併科罰款自身財產 10%～50% 或指定金額。
:::

## 第三條、禁止濫用投稿或回報行為
:::danger
違反以下規則時，即觸犯本條規定，違者必定 **機器人使用權停權** 處理。
並且開發團隊已處理過類似鳥事多次，違反本條者不得申訴。
:::
### 3.1：禁止惡意語錄投稿行為
- 3.1.1：使用` /語錄申請 `時，違反以下任一規定，即視為惡意投稿，違者必定 **機器人使用權停權**。
  - 多次申請含有H scene畫面的語錄申請者
  - 申請否決後，仍屢次申請該語錄之截圖者
  - 重複投稿高度相似語錄之圖片
  - 利用申請語錄指令洗後台者
  - 明顯投稿與視覺小說無關的語錄或圖片

### 3.2：禁止惡意回報行為
- 3.2.1：使用` /report `任一模式時，違反以下任一規定，即視為惡意回報，違者必定 **機器人使用權停權**。
  - 回報內容多為無意義文字
  - 回報內容與回報種類不符者，且為故意行為
  - 利用回報指令洗後台者
  - 明顯回報與主旨不符的圖文

:::danger
停權期限：7天～永久。
:::
## 第四條、特殊行為處罰
:::danger
違反以下規則時，即觸犯本條規定，違者必定 **機器人使用權停權** 處理。
:::

### 4.1：支援群違規特殊處罰
- 4.1.1：（試圖）對機器人支援群發動鬧事或透過鬧事被停權者加入支援群；
- 4.1.2：違反機器人支援群群規遭到停權者；
- 4.1.3：觸發支援群被盜帳號偵測系統者；

:::danger
停權期限：7天～永久。
:::
### 4.2：惡意攻擊機器人行為特殊處罰
- 4.2.1：有騷擾（包含未經同意加好友）、侮辱、辱罵、造謠開發團隊或其機器人之行為或前科者；
- 4.2.2：頻繁私訊機器人之行為經警告後仍持續之；
- 4.2.3：惡意私訊機器人行為；
- 4.2.4：於開發者所在伺服器犯下惡意行為，經開發者評估應予以停止機器人使用權為適當者；
- 4.2.5：違反《千恋＊万花機器人使用許可》第二條限制部分；
- 4.2.6：透過炸群或其他方式惡意刷機器人紀錄後台者；

:::danger
停權期限：7天～永久。
:::
### 4.3：欺騙開發團隊
- 4.3.1：申訴提交虛假證據或作偽證；
- 4.3.2：申請補償時提交虛假的證據；
- 4.3.3：欺騙開發團隊的；
- 4.3.4：罰款義務人逾時未繳納者；

:::danger
停權期限：7天～永久。
:::
### 4.4：規避懲處
- 4.4.1：被停權者使用子帳戶規避機器人處罰；
- 4.4.2：被停權者子帳戶，經開發者確定予以預防性停權；

:::danger
停權期限：10年～永久，且主帳號的停權期限延長至永久。
:::

### 4.5：惡意催更
- 4.5.1：多次重複催促或有明確的威脅或勒索行為來要求開發者更新者

:::danger
停權期限：1天～永久，或警告處分。
:::


## 附則【A】、處罰
- A.1：刑罰針對個人或伺服器有不同之刑罰處分：
  - 對個人帳號，有以下刑罰之處分：
    - 停止機器人使用權：剝奪使用或遊玩機器人之權利
      - 包含：沒收所有資產等。
    - 經濟系統停權：剝奪遊玩經濟系統有關指令之權利
    - 機器人支援群停權：剝奪加入與留存支援群之權利
    - 沒收資產：沒收經濟系統剩餘之所有財產
    - 清空電磁紀錄：清空該帳號所有的電磁紀錄
    - 罰款：裁罰一定金額為處罰
    - 警告：對情節輕微者處警告，滿兩次者處停止機器人使用權
  - 對伺服器，有以下刑罰之處分：
    - 令機器人退出伺服器：退出指定伺服器
    - 伺服器黑名單：偵測到機器人加入黑單伺服器時自動退出
- A.2：處分執行後，開發團隊不負擔保留原始電磁紀錄以供申訴之義務。
- A.3：處分執行完畢後三年內有累犯行為者，加重處罰。
- A.4：刑之裁量權由開發團隊指定，各條款下面「停權期限」僅列最低停權期限與最高停權期限為供參考用。

## 附則【B】、申訴
- B.1：遭受處分後，所有人無以下任一情況者，均可以申訴：
  - B.1.1：處分時間已逾 14 日
  - B.1.2：處分原因加註「不可申訴」之類關鍵字
  - B.1.3：處分原因為本守則第1.1、1.3.1、1.3.2、3.1、3.2、4.1.1、4.1.2、4.2（不含4.2.4）、4.3條款（包含其子條款）其一
  - B.1.4：有明確證據指出違反本守則第2.1條款
  - B.1.5：申訴人非當事人
- B.2：申訴應前往 機器人支援群 的 票務開單 頻道開單申訴。
- B.3：申訴時有 B.1 條款列出不可申訴之條件之一者，應駁回申訴。
- B.4：開發團隊有權維持原處分、修改原處分、廢棄原處分或駁回申訴。
  - B.4.1：為了減少客服行政人員壓力，有以下情況之一的冤案申訴案件，**舉證責任人為申訴當事人**。
    - 處分原因為2.1、2.2或2.3條款其一
    - 依據4.2.4條款遭到處分者
  - B.4.2：若承認該案件行為為申訴人所行為之，則是否核准其申訴或修改原處分取決於申訴人申訴當時的態度與情節輕重程度，此申訴案件最終解釋權為開發者。
  - B.4.3：以下申訴理由**並非正當的申訴理由**，採用此原因申訴者高機率被駁回申訴。
    - 「我不知道有這個規範」
    - 「這個帳號是我的兄弟姐妹」
    - 「我沒有做這個事情」（然後沒有附上說明或證據）
    - 「這個是XXX教唆我做的」
    - 「我的帳號被人盜用了！」
    - 「我花了很多時間/金錢，所以你不能封我」



## 附則【C】、聲明
- C.1：開發團隊保有解釋權與處分權；開發者保有最終解釋權、懲處最終處分權。
- C.2：於機器人支援群公告之規則，與本守則具有同等效力。
- C.3：使用、遊玩本機器人或有服務政策序言及第十六條【接受條款】之情形者，均視為已閱讀並且同意本守則。
- C.4：本守則修正時應公告於支援群，若生效後仍符合服務政策序言及第十六條之情形者，視為無異議接受修正後守則。
