# /兵役計算機 使用教學

> 指令：`/兵役計算機`（英文：`/military_service_calculator`）
> 依據：國防部《役男體位區分標準》修正草案（10/31 施行新制）
> 功能：輸入身高體重、勾選或填寫疾病狀況，自動判定**常備役／替代役（A、B 級）／免役／體位未定**。

⚠️ **重要聲明**：本工具僅供參考，實際體位以徵兵檢查醫師及體位審查結果為準。

## 1. 快速開始（四步驟）

```
/兵役計算機
   │
   ├─ ① 跳出視窗：輸入身高、體重
   ├─ ② 選擇疾病（可分類、搜尋、翻頁、複選；沒有疾病可直接略過）
   ├─ ③ 按「刷新判定」→ 依疾病跳出視窗填寫細節（可能分成多組）
   └─ ④ 顯示最終體位＋每個疾病的判定明細
```

**判定結果的顏色與圖示**

| 圖示 | 體位 | 說明 |
|---|---|---|
| 🟢 | 常備役 | 一般役男 |
| 🟡 | 替代役（A 級） | |
| 🟠 | 替代役（B 級） | |
| 🔴 | 免役 | |
| ⚪ | 體位未定 | 治療觀察期未滿一年，滿一年後複檢再定 |

**小提醒**
- 結果訊息**只有發出指令的本人能操作**，其他人按按鈕會收到提示，請自行執行指令。
- 指令有 **3 秒冷卻**；各個填寫視窗有效時間 5～10 分鐘，逾時請重新執行 `/兵役計算機`。

## 2. 步驟一：輸入身高體重

執行指令後會先跳出「兵役計算機－身高體重」視窗。

| 欄位 | 輸入方式 | 範圍 |
|---|---|---|
| 身高（公分 cm） | `170` 或 `170.5` | 100～250 cm |
| 體重（公斤 kg） | `65` 或 `65.5` | 20～300 kg |

- 身高若輸入公尺（例如 `1.7`），系統會**自動換算成公分**。
- 支援全形數字與帶單位的輸入（例如 `65公斤`）。
- 輸入不合理會以只有你看得到的訊息提醒，修正後重新執行即可。

### 身高體重的判定（附表一）

**BMI** ＝ 體重（kg）÷ 身高（m）²，**四捨五入到小數第 1 位**。

| BMI 範圍 | 體位 |
|---|---|
| 16.5 ≦ BMI ≦ 32 | 🟢 常備役 |
| 15 ≦ BMI ＜ 16.5　或　32 ＜ BMI ≦ 37.5 | 🟡 替代役 A 級 |
| BMI ＜ 15　或　37.5 ＜ BMI ≦ 45 | 🟠 替代役 B 級 |
| BMI ＞ 45 | 🔴 免役 |

| 身高 | 體位 |
|---|---|
| ≧ 150 公分 | 🟢 常備役 |
| 145～149 公分 | 🟡 替代役 A 級 |
| ≦ 144 公分 | 🔴 免役 |

BMI 與身高**兩者取較重者**，作為「身高體重初步判定」，之後會再與疾病判定合併。
（身高以無條件捨去到整數後判定，例如 149.9 視為 149。）

## 3. 步驟二：選擇疾病

提交身高體重後，畫面進入「疾病選擇」。畫面上方會顯示身高體重與初步判定、目前分類／關鍵字、總項數與頁數、已選疾病。

### 畫面元件

| 元件 | 功能 |
|---|---|
| **依分類篩選**（下拉） | 切換 13 個分類：一般（傳染病／腫瘤）、皮膚、頭頸五官口腔、胸腔呼吸、心臟血管、消化腹部、內分泌／代謝／血液、泌尿生殖、骨骼關節脊椎、耳／聽力、眼／視力、神經肌肉、精神心理 |
| **勾選您有的疾病**（多選下拉） | 勾選你有的疾病，可複選；每頁最多 25 項 |
| 🔍 **搜尋疾病** | 開啟關鍵字視窗（見下） |
| ◀️ 上頁／▶️ 下頁 | 翻頁 |
| 🗑️ 清除已選 | 清空所有已選疾病與已填答案 |
| 🔄 **刷新判定** | 確認選擇，進入填寫／出結果 |

### 搜尋怎麼用

Discord 下拉選單不能直接打字，所以用「🔍 搜尋疾病」輸入關鍵字：

- 會搜尋**項次、名稱與條文內容**；留空＝顯示全部。
- 可用**空白分隔多個關鍵字**，須**全部命中**才算符合（AND）。
- 支援常見俗名，例如：`近視`、`散光`、`高血壓`、`氣喘`、`扁平足`、`痛風`、`憂鬱`、`癲癇`、`十字韌帶`、`色盲`、`重聽`、`B肝`……
- 也可直接輸入項次，例如 `57`。
- 名稱命中的排在最前面。

### 重要特性

- **換頁、換分類、換關鍵字後，已選的疾病都會保留。**
- 取消勾選只會影響「目前這一頁」的項目，其他頁不受影響。
- 完全沒有疾病？直接按 **🔄 刷新判定**，只用身高體重判定。

## 4. 步驟三：填寫狀況

按下「🔄 刷新判定」後，系統會依你選的疾病決定要不要問你細節。

### 兩種情況

| 類型 | 說明 | 範例 |
|---|---|---|
| **直接判定** | 該項次只有單一條文，**不需詢問**，診斷確定即依該條文判定 | 項次 6 漢生病 → 免役 |
| **需要填寫** | 跳出視窗讓你勾選條文或輸入數值 | 其餘大部分項次 |

### 為什麼會分成好幾組？

Discord 規定**一個視窗最多 5 個欄位**。如果你選的疾病較多，系統會自動分組：

1. 視窗標題會顯示進度，例如「填寫狀況（1/3）」。
2. 提交一組後，原訊息會出現「📝 填寫狀況（第 2/3 組）」按鈕，按下繼續填下一組。
3. 全部完成後自動顯示結果。
4. 想改選疾病可按「↩️ 返回選擇疾病」。

### 視窗內有哪些欄位？

| 疾病類型 | 欄位 |
|---|---|
| **一般項次**（絕大多數） | 一個多選選單，列出該項次的條文，**符合的都勾**；都不符合就留空。條文超過 25 條時自動拆成多個選單（例如項次 58 有 31 條） |
| **聽力（142）** | 左耳、右耳平均聽閾（dB）＋「其他狀況」選單 |
| **視力（148）** | 左眼、右眼（矯正視力,球面,散光）＋「其他狀況」選單 |
| **胸腔呼吸（35、45～56）** | FEV1/FVC、FEV1、TLC 三個數值＋「其他狀況」選單 |
| **重要關節（130）** | 各關節的角度量測值＋「特殊狀況」選單 |

> 💡 勾選條文時，過長的條文會自動把後半段顯示在選項說明欄，不會被截掉。
> 💡 輸入格式有誤時，會列出哪個疾病的哪個欄位有問題；請回到原訊息再按一次按鈕重新填寫。

## 5. 步驟四：查看結果

### 兩個分頁

| 分頁 | 內容 |
|---|---|
| **判定結果**（預設） | 最終判定、身高體重、每個疾病一行的判定摘要與免責聲明 |
| **判定明細** | 每個疾病的判定理由（最多 3 條，其餘折疊為「另 N 項」）與提示（最多 2 條）；內容多時可用 ⏪🔙🔜⏩ 翻頁 |

結果卡片的**顏色**會跟著最終體位變色（綠／黃／橘／紅／灰）。

### 下方按鈕

| 按鈕 | 功能 |
|---|---|
| 判定結果／判定明細 | 切換分頁 |
| ✏️ **修改疾病選擇** | 回到選疾病畫面；已填過的答案會**保留**，再按刷新時只會詢問「新加入」的疾病 |
| 🔁 **重新填寫狀況** | **清除所有已填答案**，全部重新填寫（若選的疾病都不需填寫則為灰色） |

### 判定明細中的 💡 提示

部分項次會提醒你另外判定，例如：
- 「另請依第 N 項『○○』判定體位」
- 「影響運動功能時，請另選『重要關節（附表二）』輸入關節角度判定」
- 「肺功能依附表三『役男肺功能檢查判讀標準』辦理」

請依提示補選對應項次。

## 6. 疾病判定規則

### 6.1 單一疾病內：複選取最重

同一項次勾選多條時，**取最重的體位**（輕重順序：常備役 ＜ 替代役 A ＜ 替代役 B ＜ 免役）。
若勾選了「治療未滿一年」之類的**體位未定**條文，該疾病顯示為「體位未定」，並附上其餘勾選的**暫定體位**。

**一個都沒勾** → 視為不影響體位（常備役）。

### 6.2 最終判定：身高體重＋所有疾病合併

| 優先順序 | 規則 |
|---|---|
| ① | 只要**任一項為免役 → 最終免役** |
| ② | 否則只要**任一項為體位未定 → 最終體位未定**，並提示「治療觀察期滿一年後複檢再定體位；其餘項目目前暫定為 ○○」 |
| ③ | 否則取**最重**的一項 |

**例子**

| 身高體重 | 疾病 A | 疾病 B | 最終 |
|---|---|---|---|
| 🟢 常備役 | 🟡 替代役 A | 🟠 替代役 B | 🟠 替代役 B |
| 🟡 替代役 A | ⚪ 體位未定（其餘暫定 🟢） | 🟠 替代役 B | ⚪ 體位未定（暫定 🟠 替代役 B） |
| 🟢 常備役 | ⚪ 體位未定 | 🔴 免役 | 🔴 免役 |

## 7. 四種特殊項目的填寫與判定

### 7.1 聽力（項次 142）

**要填什麼**：左耳、右耳的**平均聽閾（dB）**，即 (500Hz ＋ 1000Hz ＋ 2000Hz 聽閾) ÷ 3，例如 `25`。

以「較佳耳」與「較差耳」判定：

| 體位 | 條件 |
|---|---|
| 🔴 免役 | 兩耳均＞60 dB；或一耳＞20 dB 且另耳＞70 dB；或一耳≧90 dB |
| 🟡 替代役 A | 一耳≦20 dB 且另耳＞70 dB；或兩耳均≧45 dB 且較佳耳≦60 dB |
| 🟢 常備役 | 其餘（一耳≦20 dB 且另耳 20～70 dB；或兩耳均＞20 dB 且較佳耳＜45 dB） |

另有「其他狀況」選單可勾選「進行性耳疾治療未滿一年」→ 體位未定。

### 7.2 視力（項次 148）

**輸入格式**：`矯正視力,球面度數,散光度數`（散瞳後驗光）

| 範例 | 說明 |
|---|---|
| `0.8,-6.5,-1.5` | 矯正視力 0.8、近視 650 度、散光 150 度 |
| `0.9,-7,-2` | 逗號或空白皆可分隔，也接受 `D` 字尾 |
| `1.0` | 只填視力也可（未填度數視為無屈光資料） |

> 度數用「D」為單位：**100 度 ＝ 1 D**，所以 −650 度 請填 `-6.5`。

**屈光度計算**：依備考，取散光度數的**一半**與球面度數，**符號相同則相加、相異則相減**。
例如 `-6.5,-1.5` → −6.5 ＋ (−0.75) ＝ **−7.25 D**；`-7,+2` → −7 ＋ 1 ＝ **−6 D**。

**判定（由重到輕依序檢查）**

| 體位 | 條件 |
|---|---|
| 🔴 免役 | 任一眼最佳矯正視力≦0.1 |
| 🟠 替代役 B | 屈光度最大值＞12 D；或兩眼屈光度相差＞5 D |
| 🟡 替代役 A | 任一眼矯正視力＜0.6；或屈光度＞11 D（≦12 D）；或兩眼相差＞4 D（≦5 D） |
| 🟢 常備役 | 其餘 |

「其他狀況」選單可勾選：活動性眼疾治療未滿一年（體位未定）、兩眼視野各 20 度以內、自動視野計 MD 逾 12 dB、持身心障礙證明（免役）等。

### 7.3 胸腔呼吸（肺功能，附表三）

適用項次：**35、45～56**（外傷性上呼吸道狹窄、肺結核、胸廓畸形、肋膜疾病、肺炎、胸肋骨折、肺膿瘍等、慢性支氣管炎或肺氣腫、支氣管擴張、支氣管氣喘、肺內異物、肺葉切除）。

| 欄位 | 說明 |
|---|---|
| FEV1/FVC（%） | 沒做可留空 |
| FEV1 占預測值（%） | 填了 FEV1 就**必須**一併填 FEV1/FVC |
| TLC 占預測值（%） | 限制型才需要 |

**肺功能障礙程度**

| 類型 | 輕度 | 中度 | 重度 |
|---|---|---|---|
| 阻塞型（需 FEV1/FVC ＜ 75%）— 看 FEV1 | 60～79% | 40～59% | ＜40% |
| 限制型 — 看 TLC | 65～79% | 50～64% | ＜50% |

> FEV1/FVC ≧ 75% 時不判為阻塞型。阻塞型與限制型**取較重者**。

**對應體位**：未達輕度 → 🟢 常備役；輕度 → 🟡 A 級；中度 → 🟠 B 級；重度 → 🔴 免役。
若該項次條文裡沒有對應等級，會**依序落到下一個較重的等級**。完全不填視為未達輕度。
其他不屬於「肺功能障礙」的條文（例如治療未滿一年、持身心障礙證明）在「其他狀況」選單勾選。

### 7.4 重要關節（項次 130，附表二）

在疾病清單中會看到 9 個關節各自獨立的選項：**踝、肘、髖、膝、下肢短少、頸椎、肩、腰椎、腕**。

**填寫方式**
- 在各欄位輸入**量測角度**（單位：度；下肢短少為公分）。
- **不確定或無法測量就留空**，系統只判定有填的欄位，但**至少要填一項**。
- 各欄位**分別判定，取最重者**。
- 「特殊狀況」選單：**非功能性強直或強屈 → 免役**（部分關節無此選項）；**因傷（病）治療未滿一年 → 體位未定**。

**判定門檻**（「≧」表示角度愈大愈好；「＜」表示愈小愈好）


**踝關節**（非功能性強直選項：有）

| 欄位 | 單位 | 判定門檻 |
|---|---|---|
| 蹠曲 | 度 | 常備役：≧15；替代役A：≧5；其餘：替代役B |
| 背曲 | 度 | 常備役：≧5；替代役A：≧0；其餘：替代役B |

**肘關節**（非功能性強直選項：有）

| 欄位 | 單位 | 判定門檻 |
|---|---|---|
| 彎曲攣縮 | 度 | 常備役：＜25；替代役A：＜30；替代役B：＜35；其餘：免役 |
| 屈曲 | 度 | 常備役：≧100；替代役A：≧95；替代役B：≧90；其餘：免役 |
| 內旋外轉合計 | 度 | 常備役：≧75；替代役A：≧60；替代役B：≧50；其餘：免役 |
| 過度伸張 | 度 | 常備役：＜30；替代役A：＜35；替代役B：＜40；其餘：免役 |

**髖關節**（非功能性強直選項：有）

| 欄位 | 單位 | 判定門檻 |
|---|---|---|
| 屈曲 | 度 | 常備役：≧95；替代役A：≧85；替代役B：≧75；其餘：免役 |
| 彎曲攣縮 | 度 | 常備役：＜10；替代役A：＜15；替代役B：＜20；其餘：免役 |
| 臀肌纖維化（髖彎曲範圍）（選填） | 度 | 常備役：≧85；替代役A：≧75；替代役B：≧45；其餘：免役 |

**膝關節**（非功能性強直選項：有）

| 欄位 | 單位 | 判定門檻 |
|---|---|---|
| 屈曲 | 度 | 常備役：≧125；替代役A：≧115；替代役B：≧105；其餘：免役 |
| 彎曲攣縮 | 度 | 常備役：＜20；替代役A：＜30；其餘：替代役B |
| 過度伸張 | 度 | 常備役：＜20；替代役A：＜25；替代役B：＜30；其餘：免役 |
| 內、外翻畸形 | 度 | 常備役：＜10；替代役B：＜15；其餘：免役 |

**下肢短少**（非功能性強直選項：無）

| 欄位 | 單位 | 判定門檻 |
|---|---|---|

## 8. 常見問題 FAQ

**Q1：我沒有任何疾病，怎麼用？**
輸入身高體重後，在疾病選擇畫面直接按「🔄 刷新判定」，只依身高體重判定。

**Q2：疾病太多找不到怎麼辦？**
用「🔍 搜尋疾病」輸入俗名（如「近視」「氣喘」）或項次，也可以先用分類下拉縮小範圍。

**Q3：選了很多疾病，一直跳視窗？**
Discord 一個視窗最多 5 個欄位，所以系統會自動分成多組，按原訊息上的「📝 填寫狀況」按鈕依序填完即可。

**Q4：填錯了／想改答案？**
按「🔁 重新填寫狀況」清掉所有答案重填；或「✏️ 修改疾病選擇」增減疾病（已填的答案會保留）。

**Q5：為什麼結果是「體位未定」？**
代表有項目屬於治療觀察期未滿一年。需滿一年後複檢才能確定，其餘項目的暫定體位會一併顯示。

**Q6：為什麼我勾了輕微的病，結果還是常備役？**
很多項次本來就有「不影響體位」的條文（綠燈）；沒勾任何條文也視為不影響體位。

**Q7：別人可以按我的結果嗎？**
不行，只有執行指令的本人能操作。要查詢請自行執行 `/兵役計算機`。

**Q8：按鈕沒反應／視窗失效？**
操作逾時（視窗 5～10 分鐘）。請重新執行指令。

**Q9：視窗提示「請輸入數字」？**
欄位只接受數字（含小數、負號、全形數字），多餘單位文字會被忽略，但至少要有一個數字。

**Q10：這個結果準嗎？**
依修正草案條文與附表自動計算，僅供**參考**；實際體位以徵兵檢查醫師及體位審查結果為準。
