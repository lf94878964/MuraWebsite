# `/calculator`（`/計算機`）指令說明文件

## 一、基本介紹

一個支援【純量】【向量】【矩陣】運算，並可顯示詳細計算步驟（含 LaTeX 圖片）的數學計算機指令。除了一般四則與函數外，也支援**微積分（極限／積分／級數）**、**數論函數**與**統計函數**。

| 項目 | 說明 |
|---|---|
| 指令名稱 | `/calculator`（英文）／`/計算機`（中文） |
| 運算引擎 | SymPy（精確運算優先，必要時才轉換為浮點數） |
| 運算模式 | 純量（預設）／向量／矩陣，未指定時依算式內容自動偵測（偵測到中括號 `[]` 自動切換為向量或矩陣） |
| 角度單位 | 弧度 rad（預設）／傳統角度 360°，可用選項切換 |
| 結果顯示 | Discord Components V2 頁籤介面：「計算結果」／「詳細步驟」，步驟每頁顯示 3 步並附 LaTeX 圖片 |
| 精確值／小數切換 | 結果為分數、無理數等「有小數版本」時，可用按鈕切換顯示小數（最多 12 位，超過以 `...` 表示） |

## 二、快速上手範例

> 以下「→」右邊為精確值結果；若結果有小數版本，可按「顯示小數」切換。

### 2.1 純量

| 輸入 | 結果 | 說明 |
|---|---|---|
| `1+2*3` | `7` | 先乘除後加減 |
| `2^10` 或 `2**10` 或 `2¹⁰` | `1024` | 三種次方寫法等價 |
| `10 mod 3` | `1` | 等同 `10mod3`、`mod(10,3)`、`10%3` |
| `4(2)` | `8` | 貼括號的隱式乘法 |
| `√(9+16)` | `5` | 開根號符號 |
| `5!` | `120` | 階乘 |
| `log(2,8)` | `3` | 以 2 為底、對 8 取對數 |
| `sin(30)`（角度單位：角度） | `1/2` | 角度制下 sin 30° = 1/2 |
| `sin(pi/6)`（角度單位：弧度） | `1/2` | 弧度制 |
| `C(5,2)` | `10` | 組合數 |
| `1+?+?+?`，替換值 `1,4,5` | `11` | `?` 依序被替換成 `1+1+4+5` |
| `2½` | `5/2` | 分數字元；整數緊接分數字元視為帶分數（2＋½） |
| `2^⅕` | `2^(1/5)` | 分數字元可用在次方 |
| `１２＋３×（４－１）` | `21` | 全形字元會先轉成半形再計算 |
| `random(1,6)` | 1～6 之間的隨機整數 | 引數可為小數，例如 `random(0.5,2.5)` |

### 2.2 微積分

| 輸入 | 結果 | 說明 |
|---|---|---|
| `lim (x→0) sin(x)/x` | `1` | 極限 |
| `lim (x→∞) 1/x` | `0` | 支援 ∞ |
| `∫(0 to 1) x^2 dx` | `1/3` | 定積分 |
| `∫ x^2 dx` | `x^3/3` | 不定積分（不附 `+C`） |
| `Σ(n=1 to 10) n` | `55` | 有限級數 |
| `Σ(n=1 to ∞) 1/n^2` | `π²/6` | 無窮級數（收斂） |
| `Σ(n=1 to ∞) 1/n` | `∞` | 發散時回傳 ∞ |
| `∏(n=1 to 5) n` | `120` | 連乘 |

> ⚠️ 微積分函數內請用 `6*x^2`，不要寫 `6x^2`（目前會判定不出來）。
> 微積分的算式主體會延伸到「所在括號結束」為止，若要限定範圍請自行加括號，例如 `(∫(0 to 1) x dx) + 2`。
> 極限左右不一致、定積分區間內發散時會直接報錯。

### 2.3 向量

| 輸入 | 結果 | 說明 |
|---|---|---|
| `[1,2,3]+[4,5,6]` | `[5,7,9]` | 向量加法 |
| `dot([1,2,3],[4,5,6])` | `32` | 內積：1·4 + 2·5 + 3·6 |
| `cross([1,0,0],[0,1,0])` | `[0,0,1]` | 外積（僅限 3 維） |
| `norm([3,4])` | `5` | 長度 √(3²+4²) |
| `projection([3,4],[1,0])` | `[3,0]` | 3,4 在 x 軸上的投影 |
| `angle([1,0],[0,1])`（角度單位：角度） | `90` | 夾角 |

### 2.4 矩陣

| 輸入 | 結果 | 說明 |
|---|---|---|
| `[[1,2],[3,4]]*[[5,6],[7,8]]` | `[[19,22],[43,50]]` | 矩陣乘法 |
| `[[1,2],[3,4]]**2` | `[[7,10],[15,22]]` | 矩陣冪 |
| `[[1,2],[3,4]].det()` | `-2` | 行列式（模式選「行列式」時直接輸入矩陣即可） |
| `[[1,2],[3,4]].inv()` | `[[-2,1],[3/2,-1/2]]` | 反矩陣 |
| `[[1,2],[3,4]].trace()` | `5` | 跡 |
| `[[1,2],[3,4]].rank()` | `2` | 秩 |

## 三、安全防護機制

為避免使用者輸入造成機器人卡死或記憶體爆炸，內建多道防線：

| 限制項目 | 上限 | 說明 |
|---|---|---|
| 數字輸入絕對值 | 1,000,000 | 超過會直接擋下，不進入運算 |
| 次方數（`**` / `^`） | 1,000 | 單一次方運算的指數上限 |
| 連續冪次（冪塔） | 禁止 | 例如 `9**9**9` 會被擋下，需用括號拆開，如 `9**(9**2)` |
| `factorial` / `double_factorial` / `subfactorial` / `comb` / `perm` / `H` 引數 | 500 | 避免過大的階乘、組合數運算 |
| 超階乘、質數階乘、多重階乘、數論函數、費波那契 | 各自設有輸入上限 | 超過上限會顯示錯誤訊息 |
| 向量／矩陣單一維度 | 12 | 列或欄最多 12 個元素 |
| 運算逾時 | 6 秒 | 使用獨立子行程執行，逾時強制終止，不影響主程式 |
| AST 白名單驗證 | — | 禁止屬性存取逃逸，只允許白名單內的方法 |

## 四、運算模式

| 模式 | 代碼 | 觸發方式 |
|---|---|---|
| 純量 | `scalar` | 預設模式；輸入不含中括號時使用 |
| 向量 | `vector` | 輸入含 `[...]`（非巢狀）時自動切換，或手動指定 |
| 矩陣 | `matrix` | 輸入含 `[[...]]`（巢狀中括號）時自動切換，或手動指定 |
| 行列式／積和式／對角線 | `determinant`／`permanent`／`diagonal` | 需手動選擇，直接輸入矩陣即可，不用自己打 `.det()` |

## 五、語法與輸入格式支援

| 功能 | 範例 | 說明 |
|---|---|---|
| 基本運算子 | `+` `-` `*`（`×`）`/`（`÷`）`//` `%` `**`（`^`） | 全形符號 `×` `÷` 會自動轉換 |
| 全形支援 | `（）［］｛｝`、`１２３４５６７８９０`、`．！＃＄％︿` 等 | 一律先轉成半形再計算 |
| 上標次方 | `2³` = `2^3` = `2**3` | 支援 `⁰¹²³⁴⁵⁶⁷⁸⁹` 上標數字 |
| 取餘數 | `10 mod 3` | `10 mod 3`、`10mod3`、`mod(10,3)`、`10%3` 全部等價，結果皆為 `1` |
| 隱式乘法（貼括號） | `4(2)`、`(2)4` = `8` | 大中小括號皆可；括號前為函數名稱時不適用（例如 `log10(100)` 仍是 `log10(100)` 而非乘法） |
| 數字貼常數 | `2π`、`3τ` | 等同 `2*π`、`3*τ` |
| 絕對值簡寫 | `\|x\|`、支援巢狀 `\|\|x\|+1\|` | 自動轉換為 `Abs(x)` |
| 開根號符號 | `√9`、`√(9+16)` | 自動轉換為 `sqrt(...)` |
| 分數字元 | `⅕`、`½`、`¾`、`2½`、`2^⅕` | `½` = 1/2；整數緊接分數字元視為帶分數，`2½` = 2 + 1/2 = 5/2 |
| 階乘符號 | `5!`、`(1+2)!`、`sin(30)!` | 自動轉換為 `factorial(...)`；`!` 緊跟在數字、名稱或右括號之後才算階乘 |
| 雙階乘符號 | `7!!`、`(3+3)!!` | 自動轉換為 `factorial2(...)`，`7!! = 7×5×3×1 = 105`；`0!! = 1` |
| 多重階乘 | `X!^(k)` | k 重階乘，每次遞減 k；`7!^(2)` = `7!!` = 105，`7!^(3)` = 7×4×1 = 28 |
| 子階乘符號 | `!4`、`!(2+3)`、`!sqrt(16)` | 自動轉換為 `subfactorial(...)`（錯排數：`!0=1`、`!1=0`、`!2=1`、`!3=2`、`!4=9`、`!5=44`）；`!` 在運算元**前面**時才是子階乘 |
| 質數階乘 | `7#` | 不超過 7 的所有質數之積 = 2×3×5×7 = 210 |
| 階乘混用 | `!4+5!!`、`!5!`、`2*!4` | 運算優先順序：`!`／`!!` 先於 `^`、`*`、`+`；`!5!` 讀作 `(!5)!`，即先子階乘再階乘 |
| 中／大括號 | `[ ]`、`{ }` | 純量模式下視為一般小括號；向量／矩陣模式下 `[ ]` 用於建構向量或矩陣，不可互換 |
| 十六進位 | `0x1A` | 支援 `AaCcDdFf` 字元，自動轉為十進位 |
| 千分位逗號 | `12,345` | 自動移除逗號 |
| 循環小數判定 | `0.9999999999999`（13 位以上連續 9） | 直接視為 `1` |
| 變數佔位符 | 算式：`1+?+?+?+?+?`　替換值：`1,4,5,1,4` | `?` 依序被替換值取代，組成 `1+1+4+5+1+4` |
| 常數別名 | `π`、`𝝅`、`τ` | 分別對應 `pi`、`pi`、`tau` |
| 隨機數 | `random(XX,YY)` | 取 XX～YY 之間的隨機數，支援小數（如 `random(0.5,2.5)`）；內部以精確有理數抽取，沒有浮點數誤差；引數不可是 π、√2 等無理數 |
| 微積分 | `lim`、`∫`、`Σ`、`∏` | 詳見「六、微積分」 |
| 大數自動轉換顯示 | 超過 2³¹ 的整數結果 | 不再強制輸出整數，改用小數或科學記號表示 |
| 小數精確度 | 最多顯示到小數點後 12 位 | 超過位數以 `...` 表示還有更多位數 |

### 5.1 `π(` 與 `τ(` 的判讀規則

`π`、`τ` 既是常數、也是函數名稱（質數計數函數 π(n)、因數個數 τ(n)），判讀規則如下：

| 寫法 | 判讀 |
|---|---|
| `π(10)`（前面沒有數字或運算元） | 函數：不超過 10 的質數個數 = 4 |
| `2π(3)`、`2*π(3)` | 常數相乘：2 × π × 3 |
| `τ(12)` | 函數：12 的因數個數 = 6 |
| `3τ(2)` | 常數相乘：3 × τ × 2 |

## 六、微積分

| 類型 | 語法 | 範例 | 結果 |
|---|---|---|---|
| 極限 | `lim (x→a) f(x)` | `lim (x→0) sin(x)/x` | `1` |
| 單側極限 | `lim (x→a+) f(x)`／`lim (x→a-) f(x)` | `lim (x→0+) 1/x` | `∞` |
| 無窮極限 | `lim (x→∞) f(x)` | `lim (x→∞) (1+1/x)^x` | `e` |
| 定積分 | `∫(a to b) f(x) dx` | `∫(0 to pi) sin(x) dx` | `2` |
| 不定積分 | `∫ f(x) dx` | `∫ 2*x dx` | `x^2`（不附 `+C`） |
| 級數（求和） | `Σ(n=a to b) f(n)` | `Σ(n=1 to 100) n` | `5050` |
| 無窮級數 | `Σ(n=1 to ∞) f(n)` | `Σ(n=0 to ∞) 1/2^n` | `2` |
| 連乘 | `∏(n=a to b) f(n)` | `∏(n=1 to 6) n` | `720` |

**注意事項**

- 左右極限不一致時會報錯；定積分區間內發散會報錯；級數發散時回傳 `∞`。
- 請使用 `6*x^2`，而不是 `6x^2`。
- 算式主體延伸到所在括號結束為止；要限定範圍請自行加括號。
- `∑` 會自動轉成 `Σ`；`極限`、`無窮大` 等中文字也會被轉換。

## 七、純量支援函式

### 7.1 基礎與進階運算

| 函式 | 別名 / 語法糖 | 說明與公式 | 範例 |
|---|---|---|---|
| `sqrt(x)` | `√x` | 平方根 √x | `sqrt(16)` = 4 |
| `isqrt(n)` | — | 整數平方根 ⌊√n⌋（僅限非負整數） | `isqrt(17)` = 4 |
| `cbrt(x)` | — | 立方根 ∛x | `cbrt(27)` = 3 |
| `fourthroot(x)` | — | 四次方根 x^(1/4) | `fourthroot(81)` = 3 |
| `root(x, n)` | — | 任意次方根 x^(1/n)；`n` 為奇數時支援負數輸入 | `root(-32,5)` = -2 |
| `pow(x, y)` | — | 冪次 x^y | `pow(2,10)` = 1024 |
| `exp(x)` | — | 自然指數 eˣ | `exp(0)` = 1 |
| `abs(x)` | `\|x\|` | 絕對值 | `abs(-5)` = 5 |

| `dist(p, q)` | — | 兩點間歐幾里得距離 √(Σ(pᵢ−qᵢ)²) | — |
| `random(a, b)` | — | 在 a～b 之間隨機取一個數（精確值，支援小數） | `random(0.5,2.5)` |

### 7.2 對數函數

| 函式 | 公式 | 範例 |
|---|---|---|
| `log(x)` / `ln(x)` | 自然對數 ln x（底為 e） | `ln(e)` = 1 |
| `log10(x)` / `lg(x)` | 以 10 為底 log₁₀x | `log10(1000)` = 3 |
| `log2(x)` / `lb(x)` | 以 2 為底 log₂x | `log2(8)` = 3 |
| `log(x, y)` | 以 **x** 為底、對 **y** 取對數：log_x(y) = ln y ÷ ln x | `log(2,8)` = 3 |

### 7.3 三角函數 / 反三角函數

| 類別 | 函式 | 別名 |
|---|---|---|
| 基本三角函數 | `sin(x)` `cos(x)` `tan(x)` `csc(x)` `sec(x)` `cot(x)` | `tg`（tan）、`ctg`（cot）、`cosec`（csc） |
| 反三角函數 | `asin(x)` `acos(x)` `atan(x)` `acsc(x)` `asec(x)` `acot(x)` | — |
| 半正矢族函數 | `versin` `vercosin` `coversin` `covercosin` `haversin` `havercosin` `hacoversin` `hacovercosin` | — |
| 其他古典三角函數 | `exsec(x)` `excsc(x)` `crd(x)` | — |

**基本關係式**

| 函式 | 公式 |
|---|---|
| `tan(x)` | sin x ÷ cos x |
| `csc(x)` | 1 ÷ sin x |
| `sec(x)` | 1 ÷ cos x |
| `cot(x)` | 1 ÷ tan x = cos x ÷ sin x |

**半正矢族與古典函數公式**

| 函式 | 公式 |
|---|---|
| `versin(x)` | 1 − cos x |
| `vercosin(x)` | 1 + cos x |
| `coversin(x)` | 1 − sin x |
| `covercosin(x)` | 1 + sin x |
| `haversin(x)` | (1 − cos x) ÷ 2 = sin²(x/2) |
| `havercosin(x)` | (1 + cos x) ÷ 2 |
| `hacoversin(x)` | (1 − sin x) ÷ 2 |
| `hacovercosin(x)` | (1 + sin x) ÷ 2 |
| `exsec(x)` | sec x − 1 |
| `excsc(x)` | csc x − 1 |
| `crd(x)` | 弦長 2·sin(x/2)（單位圓上圓心角 x 所對的弦長） |

> 上述函數的「輸入角度」會依照使用者選擇的角度單位（弧度／角度）自動換算；`asin`／`acos`／`atan`／`acot`／`asec`／`acsc` 等反函數的「輸出角度」也會換算成對應單位。
> 例：角度單位選「角度」時，`sin(30)` = 1/2、`acos(0)` = 90。

### 7.7 組合數學

| 函式 | 別名 | 公式 | 範例 |
|---|---|---|---|
| `factorial(x)` | `x!` | n! = n × (n−1) × … × 2 × 1，且 0! = 1 | `5!` = 120 |
| `double_factorial(x)` | `x!!`、`factorial2(x)` | n!! = n × (n−2) × (n−4) × …（直到 1 或 2），0!! = 1，僅限 0 ~ 500 | `7!!` = 105 |
| `X!^(k)` | — | k 重階乘：n × (n−k) × (n−2k) × … 直到 ≥ 1 | `7!^(3)` = 7×4×1 = 28 |
| `subfactorial(x)` | `!x` | 錯排數 !n = n! × Σₖ₌₀ⁿ (−1)ᵏ ÷ k!，亦即 !n = (n−1)(!(n−1) + !(n−2))；n 個元素完全錯位的排列數，僅限 0 ~ 500 | `!4` = 9 |
| `H(X)` | — | 超階乘（hyperfactorial）：H(n) = 1¹ × 2² × 3³ × … × nⁿ | `H(3)` = 1×4×27 = 108 |
| `sf(X)` | — | 超階乘（superfactorial）：sf(n) = 1! × 2! × 3! × … × n! | `sf(4)` = 1×2×6×24 = 288 |
| `X#` | — | 質數階乘（primorial）：不超過 n 的所有質數之積 | `7#` = 210 |
| `comb(n, k)` | `C(n,k)` | **組合數**：C(n,k) = n! ÷ (k! × (n−k)!)，從 n 個相異元素取 k 個、不計順序的方法數 | `C(5,2)` = 5! ÷ (2!×3!) = 10 |
| `perm(n, k)` | `P(n,k)` | **排列數**：P(n,k) = n! ÷ (n−k)!，從 n 個相異元素取 k 個、計順序的方法數 | `P(5,2)` = 5!÷3! = 20 |
| `H(n, k)` | `h(n,k)` | **重複組合**：H(n,k) = C(n+k−1, k)，從 n 種元素可重複取 k 個、不計順序的方法數 | `H(3,2)` = C(4,2) = 6 |

> 組合數的關係：P(n,k) = C(n,k) × k!；C(n,k) = C(n, n−k)。
> `H(X)`（單一引數）是超階乘；`H(n,k)`（兩個引數）是重複組合，依引數個數自動判斷。
> `5!^(3)` 是多重階乘，不是「階乘再 3 次方」。

### 7.10 統計函數

| `cv(a,b,...)` | — | 變異係數 CV = s ÷ x̄ | `cv(1,2,3,4)` |

## 八、向量支援函式

### 8.1 逐元素運算

向量可直接套用**所有純量函式**（逐元素運算），例如 `[1,4,9].applyfunc(sqrt)` = `[1,2,3]`。

### 8.2 向量專屬函式

設 **a** = (a₁,…,aₙ)、**b** = (b₁,…,bₙ)：

| 函式 / 語法 | 公式 | 範例 |
|---|---|---|
| `dot(v1, v2)` | 內積 **a**·**b** = a₁b₁ + a₂b₂ + … + aₙbₙ | `dot([1,2,3],[4,5,6])` = 32 |
| `cross(v1, v2)` | 外積（僅限 3 維）：**a**×**b** = (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁) | `cross([1,0,0],[0,1,0])` = [0,0,1] |
| `norm(v)` / `v.norm()` | 長度 ‖**a**‖ = √(a₁²+…+aₙ²) | `norm([3,4])` = 5 |
| `normalize(v)` | 單位化 **a** ÷ ‖**a**‖（零向量會報錯） | `normalize([3,4])` = [3/5,4/5] |
| `angle(v1, v2)` | 夾角 θ = arccos( **a**·**b** ÷ (‖**a**‖‖**b**‖) )（依角度單位輸出） | `angle([1,0],[0,1])` = π/2 或 90° |
| `projection(v1, v2)` | **a** 在 **b** 上的投影向量 = (**a**·**b** ÷ **b**·**b**) × **b** | `projection([3,4],[1,0])` = [3,0] |
| `distance(v1, v2)` / `v1.distance(v2)` | 兩點距離 ‖**a**−**b**‖ | `distance([0,0],[3,4])` = 5 |
| `v.T` | 轉置 | — |

### 8.3 支援運算

| 運算 | 說明 |
|---|---|
| `v1 + v2` / `v1 - v2` | 向量加減（逐元素） |
| `k * v` | 純量乘法 |
| `v.applyfunc(func)` | 對每個元素套用指定純量函數，例如 `v.applyfunc(sin)` |
