# `/calculator`（`/計算機`）指令說明文件

## 一、基本介紹

一個支援【純量】【向量】【矩陣】運算，並可顯示詳細計算步驟（含 LaTeX 圖片）的數學計算機指令。

| 項目 | 說明 |
|---|---|
| 指令名稱 | `/calculator`（英文）／`/計算機`（中文） |
| 運算引擎 | SymPy（精確運算優先，必要時才轉換為浮點數） |
| 運算模式 | 純量（預設）／向量／矩陣，未指定時依算式內容自動偵測（偵測到中括號 `[]` 自動切換為向量或矩陣） |
| 角度單位 | 弧度 rad（預設）／傳統角度 360°，可用選項切換 |
| 結果顯示 | Discord Components V2 頁籤介面：「計算結果」／「詳細步驟」，步驟每頁顯示 3 步並附 LaTeX 圖片 |
| 精確值／小數切換 | 結果為分數、無理數等「有小數版本」時，可用按鈕切換顯示小數（最多 12 位，超過以 `...` 表示） |

## 二、安全防護機制

為避免使用者輸入造成機器人卡死或記憶體爆炸，內建多道防線：

| 限制項目 | 上限 | 說明 |
|---|---|---|
| 數字輸入絕對值 | 1,000,000 | 超過會直接擋下，不進入運算 |
| 次方數（`**` / `^`） | 1,000 | 單一次方運算的指數上限 |
| 連續冪次（冪塔） | 禁止 | 例如 `9**9**9` 會被擋下，需用括號拆開，如 `9**(9**2)` |
| `factorial` / `comb` / `perm` / `H` 引數 | 500 | 避免過大的組合數運算 |
| 向量／矩陣單一維度 | 12 | 列或欄最多 12 個元素 |
| 運算逾時 | 6 秒 | 使用獨立子行程執行，逾時強制終止，不影響主程式 |
| AST 白名單驗證 | — | 禁止屬性存取逃逸，只允許白名單內的方法 |

## 三、運算模式

| 模式 | 代碼 | 觸發方式 |
|---|---|---|
| 純量 | `scalar` | 預設模式；輸入不含中括號時使用 |
| 向量 | `vector` | 輸入含 `[...]`（非巢狀）時自動切換，或手動指定 |
| 矩陣 | `matrix` | 輸入含 `[[...]]`（巢狀中括號）時自動切換，或手動指定 |

## 四、語法與輸入格式支援

| 功能 | 範例 | 說明 |
|---|---|---|
| 基本運算子 | `+` `-` `*`（`×`）`/`（`÷`）`//` `%` `**`（`^`） | 全形符號 `×` `÷` 會自動轉換 |
| 上標次方 | `2³` = `2^3` = `2**3` | 支援 `⁰¹²³⁴⁵⁶⁷⁸⁹` 上標數字 |
| 取餘數 | `10 mod 3` | 等同 `10 % 3` |
| 隱式乘法（貼括號） | `4(2)`、`(2)4` = `8` | 大中小括號皆可；括號前為函數名稱時不適用（例如 `log10(100)` 仍是 `log10(100)` 而非乘法） |
| 絕對值簡寫 | `\|x\|`、支援巢狀 `\|\|x\|+1\|` | 自動轉換為 `Abs(x)` |
| 開根號符號 | `√9`、`√(9+16)` | 自動轉換為 `sqrt(...)` |
| 階乘符號 | `5!`、`(1+2)!` | 自動轉換為 `factorial(...)` |
| 中／大括號 | `[ ]`、`{ }` | 純量模式下視為一般小括號；向量／矩陣模式下 `[ ]` 用於建構向量或矩陣，不可互換 |
| 十六進位 | `0x1A` | 支援 `AaCcDdFf` 字元，自動轉為十進位 |
| 千分位逗號 | `12,345` | 自動移除逗號 |
| 循環小數判定 | `0.9999999999999`（13 位以上連續 9） | 直接視為 `1` |
| 變數佔位符 | 算式：`1+?+?+?+?+?`　替換值：`1,4,5,1,4` | `?` 依序被替換值取代，組成 `1+1+4+5+1+4` |
| 常數別名 | `π`、`𝝅`、`τ` | 分別對應 `pi`、`pi`、`tau` |
| 大數自動轉換顯示 | 超過 2³¹ 的整數結果 | 不再強制輸出整數，改用小數或科學記號表示 |
| 小數精確度 | 最多顯示到小數點後 12 位 | 超過位數以 `...` 表示還有更多位數 |

## 五、純量支援函式

### 5.1 基礎與進階運算

| 函式 | 別名 / 語法糖 | 說明 |
|---|---|---|
| `sqrt(x)` | `√x` | 平方根 |

| `cbrt(x)` | — | 立方根 |

| `pow(x, y)` | — | 冪次運算 |
| `exp(x)` | — | 自然指數 |
| `abs(x)` | `\|x\|` | 絕對值 |
| `hypot(a, b)` | — | 斜邊長 √(a²+b²) |
| `dist(p, q)` | — | 兩點（可為多維座標）間的歐幾里得距離 |

### 5.2 對數函數

| 函式 | 說明 |

| `log2(x)` | 以 2 為底 |

### 5.3 三角函數 / 反三角函數

| 類別 | 函式 |
|---|---|
| 基本三角函數 | `sin(x)` `cos(x)` `tan(x)` `csc(x)` `sec(x)` `cot(x)` |

## 六、向量支援函式

### 6.1 逐元素運算

向量可直接套用**所有純量函式**（逐元素運算），例如 `[1,4,9].applyfunc(sqrt)`。

### 6.2 向量專屬函式

| 函式 / 語法 | 說明 |
|---|---|
| `dot(v1, v2)` | 內積 |
| `cross(v1, v2)` | 外積（僅限 3 維向量） |
| `norm(v)` | 向量長度（範數） |
| `v.norm()` | 同上，方法呼叫寫法 |
| `normalize(v)` | 單位化（零向量會報錯） |
| `angle(v1, v2)` | 兩向量夾角（依角度單位輸出） |
| `projection(v1, v2)` | v1 在 v2 上的投影向量 |
| `distance(v1, v2)` | 兩向量（點）間的距離 |
| `v1.distance(v2)` | 同上，方法呼叫寫法 |
| `v.T` | 轉置 |

### 6.3 支援運算

| 運算 | 說明 |
|---|---|
| `v1 + v2` / `v1 - v2` | 向量加減 |
| `k * v` | 純量乘法 |
| `v.applyfunc(func)` | 對每個元素套用指定純量函數，例如 `v.applyfunc(sin)` |

## 八、輸出與顯示

| 功能 | 說明 |
|---|---|
| 結果頁籤 | 顯示「輸入」與「輸出」，皆以 Discord 程式碼區塊（```）包裹，方便複製、避免長算式跑版 |
| 詳細步驟頁籤 | 每頁顯示 3 個步驟，附上該步驟的 LaTeX 渲染圖片，可用 ⏪第一頁／🔙上一頁／下一頁🔜／最後頁⏩ 換頁 |
| 小數／精確值切換 | 僅當結果含分數、無理數等「值得顯示小數版本」時出現，最多顯示到小數點後 12 位 |
| 圖片渲染風格 | 黑底白字，字型採用 Computer Modern（`mathtext.fontset = cm`），排版效果貼近正規 LaTeX 輸出 |
| 權限限制 | 僅發起指令者本人可操作按鈕，其他人點擊會收到僅本人可見的提示訊息 |
