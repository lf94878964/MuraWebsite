# `/數數`（`/counting`）使用說明

## 一、基本介紹

一個讓伺服器成員在指定頻道「接力數數」的小遊戲。傳統模式只要依序數 `1, 2, 3…`；進階模式則由 Bot 每一步出題（`+3`、`×2`、`x!`、`log₂`…），玩家要自己算出答案再送出，答錯就從頭開始。

| 項目 | 說明 |
|---|---|
| 指令名稱 | `/數數 設定`、`/數數 排行榜`（英文：`/counting settings`、`/counting leaderboard`） |
| 使用權限 | `設定` 需要「管理伺服器」權限；`排行榜` 所有成員都能看（目前為測試階段，僅開放給部分伺服器） |
| 伺服器限制 | **每個伺服器只能設定一個數數頻道**；要換頻道必須先移除設定（見 4.4） |
| 設定面板 | 僅本人可見，每次變更立即生效，不需要按「儲存」；只有開啟面板的人可以操作 |
| 模式 | 傳統模式（固定 +1）／進階模式（Bot 出題） |
| 玩家輸入 | 傳統模式只接受純整數；進階模式接受整數或算式（見第六節） |
| 慢速模式 | 數數頻道會被強制開啟至少 3 秒的慢速模式（見第四節） |

## 二、快速開始

1. 管理員輸入 `/數數 設定`，第一次設定請在「頻道」欄位選好數數頻道。Bot 會在該頻道宣告「數數開始」，並自動把頻道慢速模式設為 3 秒。
2. 在面板中調整模式、運算、數字範圍等設定（第四節）。
3. 成員直接在數數頻道輸入答案即可，不需要任何指令。
4. 之後再輸入 `/數數 設定`（不用填頻道）可重新開啟面板。
5. 想知道誰數得最多、最長接力幾連？輸入 `/數數 排行榜`（第八節）。
6. 想換數數頻道？先在面板按「移除設定」，再用 `/數數 設定` 指定新的頻道（每個伺服器只能有一個）。

> **Bot 必須擁有數數頻道的「管理頻道」權限**（用來強制慢速模式），沒有的話無法啟用數數系統。若要使用答錯身分組，還需要「管理身分組」權限。

## 三、遊戲規則

### 3.1 一般規則

| 規則 | 說明 |
|---|---|
| 起始數字 | 預設從 `1` 開始，可自訂（第四節） |
| 傳統模式 | 每一步固定 `+1`，直接輸入下一個整數 |
| 進階模式 | Bot 會在你**上一則成功的訊息**上貼出「下一步要做的運算」表符（貼不了就改在頻道發送），下一位玩家依此運算算出答案後送出 |
| 不能連續數 | 同一個人不能連續數兩次，違規會被 🚫 並收到提示，進度不受影響 |
| 答錯 | 答案不對會 ❌，數字回到起始數字、重新開始；若有設定「答錯身分組」，答錯者會被給予該身分組，**時間到會自動移除**（見 3.5） |
| 算式有問題 | 算式格式錯誤、超出上限、結果不是整數、計算太久等，會 ⚠️ 並回覆原因，**不算答錯**，進度不受影響 |
| 一般聊天 | 不像數數嘗試的訊息會被直接忽略，不會被當成答錯（判斷方式見 3.3） |

### 3.2 沙漏判定（搶答保護）

兩個人幾乎同時回答同一題時，慢的那位送出的其實是「剛剛已經被數出來的數字」。這種情況不該算他答錯。

- 當有人送出的數字**等於目前已經數到的數字**，而且距離上一次成功的數數不到「沙漏判定時間」，Bot 只會貼 ⏳，不算答錯、不重置。
- 兩人同時送出而其中一人慢了一步時，慢的那位也會得到 ⏳。
- 「沙漏判定時間」可在面板的下拉選單設定：**0 ~ 10 秒，每 0.5 秒一格，預設 2.5 秒**。選 `0 秒` 代表關閉沙漏判定（這時搶答的人會直接被判答錯）。
- 設定是**每個伺服器各自獨立**的。

### 3.3 哪些訊息會被當成數數嘗試

| 模式 | 條件 |
|---|---|
| 傳統模式 | 整串訊息必須是純整數（可帶負號） |
| 進階模式 | 開頭是數字、`(`、`√`、`\|`、`π`、`-`，或是「函式名稱＋`(`」（如 `log10(100)`），或是 `!` 後面緊接數字／`(`（子階乘，如 `!4`）；長度不得超過 200 字 |

所以一般機器人指令（例如 `!play`）不會被當成數數嘗試。

### 3.4 規則更新

如果管理員在遊戲進行中改了設定，導致目前這一步的題目已經不合法（例如結果超出新的數字範圍），Bot 會自動換題並公告「規則已更新」，這不算任何人答錯。

### 3.5 答錯身分組的限時機制

- 答錯的人會被給予管理員指定的身分組，**經過設定的時間後自動移除**。
- 給予時間可設定 **1 ~ 120 分鐘，預設 5 分鐘**。
- 在身分組還沒到期前又答錯，時間會**重新計算**。
- 如果答錯的人本來就持有該身分組（不是數數系統給的），Bot 不會動它，也不會自動移除。
- 即使 Bot 中途重新啟動，尚未到期的身分組仍會在時間到時被移除。
- 修改給予時間只影響之後答錯的人，已經在計時的不受影響。

### 3.6 慢速模式（強制）

- 數數頻道一律會開啟慢速模式，**最低 3 秒**，不能關閉。
- 管理員可以在面板設定更長的秒數（3 秒起，最長 6 小時）；設定後 Bot 會直接把頻道慢速模式改成該秒數。
- 如果有人在 Discord 的頻道設定中把慢速模式調到 **3 秒以下**（包含關閉），Bot 會立刻改回；即使遊戲已經開始也一樣。
- 慢速模式設為 3 秒以上的值（例如 10 秒）時，Bot 不會干涉。
- Bot 重新啟動時也會檢查一次數數頻道。
- **Bot 必須有「管理頻道」權限**：沒有的話，`/數數 設定` 會拒絕設定該頻道；已啟用後如果權限被收回，數數會暫停，Bot 會在頻道提醒（每 5 分鐘最多一次），授予權限後即自動恢復。

## 四、設定面板

| 按鈕／選單 | 說明 |
|---|---|
| 切換為傳統／進階模式 | 切換後會重置進度 |
| 負數：允許／不允許 | 允許時數字範圍為 `-上限 ~ +上限`，不允許時為 `0 ~ +上限`；目前數字超出新範圍時會重置進度 |
| 數字上限 | 4 ~ 16 位數字，介於 `1,000` ~ `9,999,999,999,999,999`；預設 `999,999,999,999` |
| 起始數字 | 預設 `1`，可輸入負數；必須在目前的數字範圍內；設定後會重置進度 |
| 重置進度 | 數字回到起始數字，重新出題 |
| 運算範圍（僅進階模式） | 進入子頁面，限制每種運算「出現的參數範圍」，見第五節 |
| 附加屬性（僅進階模式） | 無／嚴格遞增／嚴格遞減，見 4.2；切換後會重置進度 |
| 啟用運算（僅進階模式） | 多選，決定 Bot 會出哪些類別的題目，見 4.1 |
| ⏳ 沙漏判定時間 | 下拉選單，0 ~ 10 秒、每 0.5 秒一格，預設 2.5 秒，見 3.2 |
| 🐢 頻道慢速模式 | 下拉選單，最低 3 秒（預設 3 秒），選擇後立即套用到數數頻道，見 3.6 |
| 答錯身分組 | 答錯的人會被給予的身分組，可不選；Bot 需要「管理身分組」權限，且該身分組要在 Bot 身分組之下 |
| 身分組給予時間 | 按鈕，點開後輸入 1 ~ 120 分鐘（預設 5 分鐘），時間到自動移除，見 3.5 |
| 🗑️ 移除設定 | 紅色按鈕，會先跳出確認頁；移除這個伺服器的數數系統，見 4.4 |

### 4.1 可啟用的運算類別

**加法一定會出現**，不能關閉（嚴格遞減模式除外）。其餘類別可自由勾選：

| 類別 | 內容 | 限制 |
|---|---|---|
| 減法 | `-1` ~ `-9` | — |
| 乘法 | `×1` ~ `×9` | — |
| 除法 | `÷1` ~ `÷9` | 僅限整除 |
| 次方 | `x^0` ~ `x^9` | 結果過大時不會出現 |
| 對數 | `log2` ~ `log10` | 僅限整數結果（例如 4096 才會有 `log2`） |
| 根號 | `√x`、`∛x`、`∜x`、`5√x` ~ `9√x` | 僅限整數結果 |
| 階乘 | `x!` | x ≤ 20 |
| 雙階乘 | `x!!` | x ≤ 40 |
| 子階乘 | `!x` | x ≤ 20 |
| 取餘數 | `mod1` ~ `mod9` | — |
| 歐拉函數 | `φ(x)` | x ≤ 10¹² |
| 絕對值 | `\|x\|` | 只有負數會出現（避免「原地不動」的題目） |
| 排列 | `P(x,1)` ~ `P(x,9)` | x ≤ 30 |
| 組合 | `C(x,1)` ~ `C(x,9)` | x ≤ 40 |
| 重複組合 | `H(x,1)` ~ `H(x,9)` | x ≤ 30 |

出題時，只要某個運算的結果不是整數、超出數字範圍，就不會成為候選。

### 4.2 附加屬性

| 屬性 | 規則 | 不能使用的類別 |
|---|---|---|
| 無 | 沒有限制 | — |
| 嚴格遞增 | 每一步的結果都必須比上一個數字大；數到上限後回到「起始數字」重新開始（會公告 🏁） | 減法、除法、取餘數、對數、根號、歐拉函數 |
| 嚴格遞減 | 固定從數字上限開始，每一步都必須更小；數到下限後回到數字上限重新開始（會公告 🏁）；**減法為必選** | 乘法、次方、階乘、雙階乘、子階乘、排列、組合、重複組合、絕對值（加法在此模式下不會出現） |

### 4.3 出題的傾向

Bot 並不是完全平均地抽題，為了讓遊戲比較順暢，會有一些傾向：

- **數字很小**時，不會出除法、對數、取餘數，並且偏好讓數字變大，很少出現大幅縮小數字的題目。
- **數字很大**時，取餘數與對數出現的機率會提高。
- 當數字**剛好有整數對數值**（例如 4096）時，對數類題目更容易出現。
- **數字貼近上限**時，會偏好讓數字變小的運算，避免卡在上限；若真的沒有可用的運算，會自動改用減法。
- **目前數字是 0** 時，不會出「結果仍是 0」的運算。
- 次方、對數、根號、階乘等特殊運算，出現機率略高一些。

### 4.4 移除設定

每個伺服器只能設定一個數數頻道。想換頻道、或不想再玩了，就在設定面板按紅色的「**移除設定**」，確認後即可。

| 項目 | 移除後 |
|---|---|
| 數數設定、目前的數數進度 | **刪除** |
| 排行榜的歷史紀錄 | 保留（之後重新設定，仍能在 `/數數 排行榜` 看到） |
| 尚未到期的答錯身分組計時 | 保留，時間到仍會自動移除 |
| 頻道的慢速模式 | 維持目前的設定，不會自動關閉 |

移除後該頻道不再有數數功能；之後用 `/數數 設定` 重新指定頻道即可重新開始（會從起始數字開始新的一輪）。

## 五、運算範圍設定

「運算範圍」讓管理員限制有參數的運算「參數可以出現多大」。例如加法的參數是 1 ~ 9，把它設成 `+2 ~ +5`，Bot 就只會出 `+2`、`+3`、`+4`、`+5`。

### 5.1 怎麼設定

1. 在主面板按「**運算範圍**」進入子頁面。
2. 用第一個選單選擇要設定的運算類別（加法，以及目前已啟用且有參數的類別）。
3. 用第二、三個選單分別設定「最小」與「最大」的參數。
   - 如果把最小調得比最大還大，最大會自動跟著拉高（反過來亦同），範圍一定保持合法。
4. 每次選擇都會立即生效。按「**返回設定**」回到主面板，按「**全部恢復預設**」清除所有自訂範圍。

### 5.2 哪些類別可以設定

| 類別 | 參數意義 | 可設定的範圍 |
|---|---|---|
| 加法／減法／乘法／除法 | `+k`／`-k`／`×k`／`÷k` 的 k | 1 ~ 9 |
| 次方 | `x^k` 的 k | 0 ~ 9 |
| 對數 | `log_k` 的底數 k | 2 ~ 10 |
| 根號 | k 次方根 | 2 ~ 9 |
| 取餘數 | `mod k` 的 k | 1 ~ 9 |
| 排列／組合／重複組合 | `P(x,k)`／`C(x,k)`／`H(x,k)` 的 k | 1 ~ 9 |

階乘、雙階乘、子階乘、歐拉函數、絕對值沒有參數，所以不需要也不能設定範圍。

### 5.3 注意事項

- 範圍只在**進階模式**有效；傳統模式固定 `+1`。
- 範圍只影響「Bot 之後出的題目」，目前這一題不受影響；設定會被保留，即使之後關閉某個類別再重新啟用，範圍仍在。
- 如果範圍讓某個數字「走不動」（例如數字貼近上限，而加法被限制在 `+5 ~ +9`），Bot 會改用減法；若減法的設定範圍也走不動，就暫時忽略範圍、使用完整的 `-1 ~ -9`，避免卡關。
- 面板的摘要會列出所有已自訂的範圍；沒有自訂的類別視為完整範圍。

## 六、玩家怎麼輸入答案

### 6.1 傳統模式

直接輸入下一個整數，例如目前是 `41`，就輸入 `42`。

### 6.2 進階模式

可以輸入單純的整數，也可以輸入算式讓 Bot 幫你算，例如：

| 題目 | 目前數字 | 可接受的輸入 |
|---|---|---|
| `+3` | 10 | `13`、`10+3`、`(5+8)` |
| `×4` | 6 | `24`、`6*4`、`6×4` |
| `x!` | 5 | `120`、`5!` |
| `x!!` | 7 | `105`、`7!!`、`7*5*3` |
| `!x` | 4 | `9`、`!4` |
| `log2` | 4096 | `12`、`log2(4096)` |
| `√x` | 144 | `12`、`sqrt(144)`、`√144` |
| `P(x,2)` | 5 | `20`、`perm(5,2)`、`P(5,2)` |

- 算式語法與 `/計算機` 相同（運算子、`^` 次方、`mod`、`|x|`、`√`、`!`、`!!`、`!x`、各種函式…），詳見《計算機說明文件》。
- **階乘符號**：`5!` 是階乘、`7!!` 是雙階乘（`7×5×3×1`）、`!4` 是子階乘（錯排數 9）。子階乘的 `!` 要寫在數字或左括號前面，且緊接不能有空白。
- 角度函數一律使用**弧度**。
- 算式的結果必須是**整數**，不能是向量或矩陣。

### 6.3 算式的限制

| 限制項目 | 說明 |
|---|---|
| 算式中的數字 | 不能超過這個頻道的數字上限，例如上限 `1,000,000`，算式裡就不能出現 `1000001` |
| 次方數（`^`） | 次方的指數不能超過 1,000 |
| 連續冪次 | 不能連寫，如 `9^9^9` 會被擋下，請用括號拆開 |
| 算式長度 | 最多 200 字，超過會被當成一般聊天 |
| 計算時間 | 算太久（數字過大或算式過於複雜）會 ⚠️ 提示簡化算式，不算答錯 |

## 七、表符與訊息一覽

| 表符 | 意義 |
|---|---|
| ✅ | （傳統模式）答對了 |
| 運算表符（如 `+3`） | （進階模式）答對了，這是「下一步」要做的運算 |
| ❌ | 答錯，進度重置 |
| 🚫 | 同一個人連續數數 |
| ⏳ | 搶答保護，或別人比你早一步更新了進度；也用於規則更新時 |
| ⚠️ | 算式有問題（格式錯誤、超出上限、不是整數、計算太久…），不算答錯 |
| 🏁 | 嚴格遞增／遞減模式走到盡頭，回到起點重新開始 |

## 八、排行榜

輸入 `/數數 排行榜` 即可（所有成員都能使用），結果會公開顯示在頻道中。

### 8.1 怎麼操作

- 用第一個下拉選單切換**排行類別**，第二個切換**時間範圍**。
- 每頁 10 筆，用「上一頁／下一頁」翻頁；「重新整理」會重新統計。
- 玩家排行的最下面會顯示「**你的排名**」。
- 只有輸入指令的人能操作這個面板，其他人想看請自己輸入指令。

**時間範圍**（以台灣時間計算）：全部時間、本月（從 1 號開始）、本週（從星期一開始）、今日（從 00:00 開始）。

### 8.2 排行類別

**玩家排行**

| 類別 | 說明 |
|---|---|
| 🔢 數數貢獻榜 | 答對次數最多的人，並顯示占全部答對次數的比例 |
| 💥 答錯榜 | 答錯次數最多的人 |
| 🎯 正確率榜 | 正確率最高的人；至少要有 10 次嘗試才會列入 |
| 🏔️ 最大數字榜 | 親手數出最大數字的人 |
| 🔥 個人連對榜 | 自己連續答對最多次（中間沒有答錯；別人的答錯不算） |
| 📅 活躍天數榜 | 有數數的天數最多的人 |
| 🧮 算式達人榜 | 用算式（而不是直接打數字）答對最多次的人 |
| 🔨 終結者榜 | 答錯時打斷最長接力的人，也會顯示打斷過幾次接力 |

**全伺服器排行**

| 類別 | 說明 |
|---|---|
| ⛓️ 最長接力紀錄 | 全伺服器連續答對最久的紀錄，會標示是誰答錯終結、哪一天，以及目前進行中的接力 |
| 😈 最難運算榜 | 答錯率最高的運算；至少要有 10 次嘗試才會列入 |
| 🎲 最常出現運算 | 被出題最多次的運算，並顯示答對率 |
| 🕒 熱門時段 | 一天中哪個小時（台灣時間）最多人數數 |
| 🔥 最熱鬧的日子 | 單日答對次數最多的日期，以及當天有幾人參與 |

### 8.3 注意事項

- 「接力」指**全伺服器連續答對的次數**，直到有人答錯，或管理員重置進度（例如切換模式、按「重置進度」）為止。
- 選擇「本月／本週／今日」時，接力與連對只計算範圍內的數數，所以跨過範圍起點的接力會被截斷。
- 運算相關的排行（最難運算、最常出現運算）只統計這個功能更新之後的紀錄，更早的紀錄沒有記下運算。
- 更新之前的紀錄沒有「重置」標記，所以更早的接力紀錄可能把被管理員重置的幾輪連在一起算。
- 「算式達人榜」只算答對的次數；直接輸入數字不算算式。
- 離開伺服器的玩家仍會出現在排行中，名稱可能顯示為「用戶 ＋ 編號」。
- 移除設定後，排行榜紀錄仍保留，可以繼續查看。

## 九、常見問題

| 問題 | 回答 |
|---|---|
| 為什麼我的答案被 ⚠️ 而不是 ❌？ | ⚠️ 代表算式本身有問題（格式、超出上限、不是整數…），Bot 沒辦法判斷對錯，所以不算答錯 |
| 為什麼我明明答對卻是 ⏳？ | 有人比你早一步送出了同一題的答案；這是正常的搶答保護 |
| 沙漏判定時間要設多少？ | 頻道很熱鬧、常有人搶答就設長一點（例如 3 ~ 5 秒）；想要嚴格一點就調短，設 0 秒則完全關閉 |
| 運算範圍改了，為什麼目前這題沒變？ | 範圍只影響之後出的題目；想立刻套用請按「重置進度」 |
| 加法可以被關掉嗎？ | 不行，加法是必要運算（嚴格遞減模式下改為必選減法） |
| 為什麼 `!play` 沒有反應？ | 子階乘的 `!` 後面必須緊接數字或左括號，所以一般機器人指令不會被當成數數嘗試 |
| 答錯的身分組什麼時候會被移除？ | 依面板設定的「身分組給予時間」（1 ~ 120 分鐘，預設 5 分鐘），時間到會自動移除；在到期前再次答錯會重新計時 |
| 可以把慢速模式關掉或調成 1 秒嗎？ | 不行，數數頻道至少 3 秒；如果在頻道設定中改低，Bot 會立刻改回 |
| 我設了 10 秒的慢速模式，在 Discord 裡改成 5 秒會被改回嗎？ | 不會，只有低於 3 秒才會被強制改回；想變回 10 秒請在面板重新選擇 |
| `/數數 設定` 說沒有「管理頻道」權限？ | Bot 必須擁有數數頻道的「管理頻道」權限才能啟用，請先授予（頻道權限或伺服器身分組皆可）再重新輸入指令 |
| 數數突然暫停並提醒缺少權限？ | Bot 的「管理頻道」權限被收回了，授予後數數會自動恢復 |
| 為什麼不能指定第二個數數頻道？ | 每個伺服器只能設定一個數數頻道。想換的話，先開 `/數數 設定`，按面板上的「移除設定」，再指定新的頻道 |
| 移除設定後排行榜會消失嗎？ | 不會，歷史紀錄會保留；重新設定後仍然看得到 |
| 排行榜為什麼沒有我的名字？ | 該類別可能需要門檻（正確率、最難運算要 10 次嘗試），或你在選擇的時間範圍內還沒有紀錄 |
| 排行榜可以只看本週嗎？ | 可以，在排行榜的第二個下拉選單選「本週」即可 |
| 身分組沒有被給予或移除？ | 請確認 Bot 有「管理身分組」權限，且該身分組的位置在 Bot 最高身分組之下 |
