# 🀄 萬家樂（澳門規章版百家樂）玩法與規則介紹

> 萬家樂是澳門版本的百家樂：一樣是押「閒家」、「莊家」或「和局」，但**補牌規則更簡單**、**和局賠率更高**，還多了「**閒對子／莊對子**」下注。
> 整局**全自動發牌**，只要下注、等結果。**支援多人同桌跟注**。
> 本遊戲的補牌規則參考《萬家樂法定規章》第九條「方式一」。

---

## 快速開始

```
/賭博 萬家樂 bet:500 bet_type:押閒家
```

（英文介面為 `/gb wanjiale`）

| 參數 | 說明 |
| --- | --- |
| `bet` | 下注金額（柚子幣），**最低 25**，且不可超過你的餘額 |
| `bet_type` | 押注選項：**押閒家、押莊家、押和局、押閒對子、押莊對子** |

輸入指令後，頻道會出現一個「**招募下注中**」的大廳訊息，你就是**開局玩家**。其他人可以在 10 分鐘內加入下注，你可以隨時按「開始遊戲」提早開局。

## 與一般百家樂有什麼不同？

| 項目 | 一般百家樂（本 Bot 的百家樂） | 萬家樂 |
| --- | --- | --- |
| 補牌規則 | 閒家 0 至 5 點補牌，莊家依複雜的對照表 | **更簡單**：依雙方點數高低決定誰補牌（見下方） |
| 佣金 | 只有「**莊家**贏」抽 5% | **閒家或莊家任一方以 7、8、9 點獲勝**，都抽 5% |
| 和局賠率 | 1 賠 8 | **1 賠 14** |
| 對子下注 | 無 | **閒對子、莊對子**，賠率 **1 賠 11** |
| 牌組 | 一副牌（52 張） | **8 副牌**（416 張）洗成牌靴 |

## 遊戲流程

1. **開局**：開局者輸入指令，建立招募大廳（限時 **10 分鐘**）。
2. **招募**：所有人都可以點按鈕選擇押注選項、輸入金額加入。
3. **開始**：開局者按「開始遊戲」，或 10 分鐘到期**自動開始**。此時系統才會**統一扣款**。
4. **發牌**：閒家、莊家各發 2 張牌，**閒家先亮牌**，再亮莊家牌。
5. 依補牌規則決定是否增牌。
6. **比點數**，依你的下注選項**自動派彩**，同時判定對子下注。
7. 結算訊息會列出每位玩家的下注與輸贏。

## 點數計算

| 牌 | 點數 |
| --- | --- |
| A | 1 點 |
| 2 至 9 | 牌面點數 |
| 10、J、Q、K | **0 點** |

- 手牌點數**加總後只取個位數**。例如 `7 + 8 = 15` → **5 點**。
- 最高 9 點，最低 0 點。

## 補牌規則

萬家樂的補牌流程只有「**例牌**」、「**點數相同**」、「**點數不同**」三種情況，且每家**最多只會增加 1 張牌**（最多 3 張）：

### ① 例牌（Natural）

閒家或莊家**前兩張牌合計為 8 或 9 點** → **雙方都不再增牌**，直接比大小。

### ② 雙方前兩張點數相同（0 至 7 點）

**雙方各增牌一張**（閒家先增），然後比大小。

### ③ 雙方前兩張點數不同（且沒有例牌）

1. **點數較低的一方先增牌一張。**
2. 增牌後看他的點數：
   - 如果增牌後**仍然小於**對家原本的點數 → **對家不用增牌，直接獲勝**。
   - 如果增牌後**大於或等於**對家原本的點數 → **對家也必須增牌一張**，然後比大小。

### 範例

| 閒家 | 莊家 | 過程 |
| --- | --- | --- |
| 3 點 | 6 點 | 閒家較低 → 閒家先增牌，拿到 2 → 5 點 < 6 點 → **莊家不增牌，直接勝出** |
| 3 點 | 6 點 | 閒家先增牌，拿到 4 → 7 點 ≥ 6 點 → **莊家也要增牌一張**，再比大小 |
| 5 點 | 5 點 | 點數相同 → 雙方各增一張，再比大小 |
| 8 點 | 2 點 | 閒家例牌 → 不增牌，閒家 8 點直接贏 |


### 對子下注

| 押注 | 條件 | 淨賺 | 實際入帳（含本金） |
| --- | --- | --- | --- |
| **押閒對子** | 閒家**前兩張牌點數相同** | **11 倍** | 12 倍 |
| **押莊對子** | 莊家**前兩張牌點數相同** | **11 倍** | 12 倍 |

- 對子的「點數相同」是指**牌面相同**，例如 `8 與 8`、`K 與 K`；花色不拘。
- `10 與 K` 雖然都是 0 點，但牌面不同，**不算對子**。
- 對子下注**與勝負無關**：就算和局或你支持的那一方輸了，只要前兩張是對子，就算贏。
- 沒中就沒收本金。

### 重點說明

- 🧀 **和局時，押閒家／莊家的玩家本金全額退回**。
- 💰 5% 佣金採**無條件捨去**。例如押 25，7 點贏淨賺 `int(25 × 0.95) = 23`。
- 💡 結算畫面會顯示「某方以幾點獲勝，抽取 5% 佣金」，以及「閒對子成立」「莊對子成立」的提示。

## 多人跟注（招募大廳）

### 大廳畫面

開局後會看到「🀄 萬家樂・招募下注中」，上面列出：
- 開局玩家
- 簡要賠率（閒／莊 1 賠 1，7、8、9 點勝出抽 5%；和局 1 賠 14；對子 1 賠 11）
- 目前所有人的下注名單

### 如何加入下注

1. 點大廳下方的按鈕（**押閒家／押莊家／押和局／押閒對子／押莊對子**）。
2. 跳出視窗，輸入**下注金額**，送出。
3. 你會收到只有你自己看得到的「✅ 下注成功」訊息，大廳名單同步更新。

### 大廳規則

| 項目 | 說明 |
| --- | --- |
| 每人下注數 | **只能押一個選項**。再按一次會**覆蓋**舊下注 |
| 誰能開始 | 只有**開局者**能按「開始遊戲」 |
| 自動開始 | **10 分鐘**到期自動開局 |
| 扣款時機 | **遊戲開始的那一刻才扣款** |
| 餘額不足 | 開始時若餘額比下注金額少，系統會**以目前餘額為準**下注 |
| 最低下注 | 25 柚子幣 |
| 開始後 | 不能再下注或修改 |

> ⚠️ 因為是開局時才扣款，請**確保開局時餘額足夠**。

## 結算後再開新局

結算畫面下方有五個按鈕：**押閒家／押莊家／押和局／押閒對子／押莊對子（新局）**。

- **任何人都可以按**，按的人成為**新一局的開局者**。
- 跳出視窗，預設帶入你**上一局的下注金額**（沒玩過則預設 100），可修改。
- 送出後，原本那則訊息會**變成新一局的招募大廳**，大家重新下注。
- 按鈕有效時間 **10 分鐘**，冷卻 5 秒。

## 勝率與期望值參考

依本 Bot 的實際規則（8 副牌）模擬約 **60 萬至 150 萬局**，僅供參考：

| 結果 | 機率 |
| --- | --- |
| 閒家贏 | 約 **47.1%** |
| 莊家贏 | 約 **47.1%** |
| 和局 | 約 **5.8%** |
| 閒家前兩張是對子 | 約 **7.5%** |
| 莊家前兩張是對子 | 約 **7.5%** |

| 下注選項 | 平均每 1 柚子幣的期望損益 |
| --- | --- |
| 押閒家 | 約 −0.015（−1.5%） |
| 押莊家 | 約 −0.015（−1.5%） |
| 押和局 | 約 −0.13（−13%） |
| 押閒對子／莊對子 | 約 −0.10（−10%） |

**結論**：閒、莊兩邊的期望損益幾乎一樣；和局與對子是高賠率、高風險的選項。

## 常見問題 FAQ

**Q：萬家樂和百家樂我該選哪個？**
A：萬家樂補牌規則簡單、和局賠率高（14 倍）、還有對子下注；百家樂則是傳統規則，只有莊家贏才抽佣。兩者都是純運氣。

**Q：為什麼我押閒家贏了，入帳只有 1.95 倍？**
A：萬家樂的規則是**任一方以 7、8、9 點獲勝都抽 5% 佣金**，不只莊家。

**Q：我押閒對子，閒家輸了還能拿錢嗎？**
A：可以，對子下注與勝負無關，只要閒家前兩張牌點數相同就中。

**Q：10 和 K 算對子嗎？**
A：不算，必須是**牌面相同**（例如兩張 K）。

**Q：每個人可以同時押主注和對子嗎？**
A：不行，每人只能押**一個**選項，後押的會覆蓋先押的。

**Q：和局的時候押對子會輸嗎？**
A：不會因為和局而輸，只看你押的那一方前兩張是不是對子。

## 新手小提示

- 萬家樂沒有必勝策略，每局都是獨立事件。
- 想穩一點 → 押閒或押莊；想搏一把 → 押和局（14 倍）或對子（11 倍），但要有心理準備。
- 開局者按「開始遊戲」前，記得確認**自己與朋友的餘額都足夠**。
