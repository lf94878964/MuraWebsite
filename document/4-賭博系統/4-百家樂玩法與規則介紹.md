# 🃏 百家樂（Baccarat）玩法與規則介紹

> 押注「閒家」、「莊家」或「和局」哪一方會贏。
> 整局**全自動發牌**，不需要做任何決定，只要下注、等結果。**支援多人同桌跟注**。


---

## 快速開始

```
/賭博 百家樂 bet:500 bet_type:押閒家
```

（英文介面為 `/gb baccarat`）

| 參數 | 說明 |
| --- | --- |
| `bet` | 下注金額（柚子幣），**最低 25**，且不可超過你的餘額 |
| `bet_type` | 押注選項：**押閒家**、**押莊家**、**押和局** |

輸入指令後，頻道會出現一個「**招募下注中**」的大廳訊息，你就是**開局玩家**。其他人可以在 10 分鐘內加入下注，你可以隨時按「開始遊戲」提早開局。

---

## 遊戲流程

1. **開局**：開局者輸入指令，建立招募大廳（限時 **10 分鐘**）。
2. **招募**：所有人都可以點下方按鈕選擇押注選項、輸入金額加入（見[多人跟注](#多人跟注招募大廳)）。
3. **開始**：開局者按「開始遊戲」，或 10 分鐘到期**自動開始**。此時系統才會**統一扣款**。
4. **發牌**：閒家、莊家各發 2 張牌（先蓋著）。
5. **閒家亮牌**。
6. 若任一方是「**例牌**」（前兩張牌 8 點或 9 點）→ 不再補牌，直接比點數。
7. 否則依[補牌規則](#補牌規則)：閒家先決定補不補牌，再輪到莊家。
8. **比點數**，分出「閒家贏／莊家贏／和局」，依你的下注選項**自動派彩**。
9. 結算訊息會列出每位玩家的下注與輸贏。

> 🎬 整個過程會用同一則訊息逐步更新（發牌 → 亮牌 → 補牌 → 結算），不用任何操作。

## 點數計算

| 牌 | 點數 |
| --- | --- |
| A | 1 點 |
| 2 ~ 9 | 牌面點數 |
| 10、J、Q、K | **0 點** |

- 將手牌點數**全部加總後只取個位數**。例如 `7 + 8 = 15` → **5 點**；`K + 9 = 9` → **9 點**。
- 最高 9 點（天生贏家），最低 0 點。
- 每局使用**一副新洗好的牌**（52 張）。

---

## 補牌規則

百家樂的補牌**完全由規則決定**，玩家與莊家都沒有選擇權。

### 例牌（Natural）

閒家或莊家的**前兩張牌合計為 8 或 9 點**時，稱為「例牌」，**雙方都不再補牌**，直接比點數。

### 閒家補牌

| 閒家點數 | 動作 |
| --- | --- |
| 0 ~ 5 | **補一張牌** |
| 6 ~ 7 | 停牌 |

### 莊家補牌

**情況一：閒家沒有補牌（閒家停牌）**

| 莊家點數 | 動作 |
| --- | --- |
| 0 ~ 5 | 補牌 |
| 6 ~ 7 | 停牌 |

**情況二：閒家有補牌** —— 依「莊家目前點數」與「閒家第三張牌的點數」決定：

| 莊家點數 | 閒家第三張牌點數 → 莊家補牌 | 莊家停牌的情況 |
| --- | --- | --- |
| 0 ~ 2 | **一律補牌** | — |
| 3 | 除了 8 以外都補 | 閒家第三張為 8 |
| 4 | 第三張為 **2 ~ 7** 時補 | 第三張為 0、1、8、9 |
| 5 | 第三張為 **4 ~ 7** 時補 | 第三張為 0、1、2、3、8、9 |
| 6 | 第三張為 **6 或 7** 時補 | 其他情況 |
| 7 | **不補牌** | 一律停牌 |

> 這就是標準的百家樂補牌表，不需要背，系統會自動處理。

## 下注選項與賠率

以下以你的**下注金額 = 1** 為基準：

| 押注 | 開出結果 | 淨賺 | 實際入帳（含本金） |
| --- | --- | --- | --- |
| **押閒家** | 閒家贏 | **1 倍** | 2 倍 |
| | 和局 | 0 | 退回本金 |
| | 莊家贏 | −1 倍 | 0 |
| **押莊家** | 莊家贏 | **0.95 倍**（扣 5% 佣金） | 1.95 倍 |
| | 和局 | 0 | 退回本金 |
| | 閒家贏 | −1 倍 | 0 |
| **押和局** | 和局 | **8 倍** | 9 倍 |
| | 閒家或莊家贏 | −1 倍 | 0 |

### 重點說明

- 🧀 **和局時，押閒家／莊家的玩家本金全額退回**，不輸不贏。
- 🏦 莊家贏的 5% 佣金採**無條件捨去**。例如押 25 柚子幣，淨賺 `int(25 × 0.95) = 23`。
- 🤝 押和局賠率高，但開出機率只有約 9%，屬於高風險選項。

### 關於「幸運六」

「幸運六」（莊家以 6 點贏）的**專屬押注目前沒有開放**。
有時結算畫面會出現 `✨ 幸運六！` 的提示，那只是顯示資訊，**不會改變上表的任何賠付**。

## 多人跟注（招募大廳）

### 大廳畫面

開局後會看到「🃏 百家樂・招募下注中」，上面列出：

- 開局玩家
- 目前所有人的下注名單（誰、押什麼、多少錢）

### 如何加入下注

1. 點大廳下方的 **押閒家／押莊家／押和局** 按鈕。
2. 跳出視窗，輸入你想下注的**金額**，送出。
3. 你會收到只有你自己看得到的「✅ 下注成功」訊息，大廳名單同步更新。

### 大廳規則

| 項目 | 說明 |
| --- | --- |
| 每人下注數 | **只能押一個選項**。再按一次會**覆蓋**舊下注（可換邊、改金額） |
| 誰能開始 | 只有**開局者**能按「開始遊戲」，其他人按會被提示 |
| 自動開始 | **10 分鐘**到期自動開局 |
| 扣款時機 | **遊戲開始的那一刻才扣款**，下注期間不會先扣 |
| 餘額不足 | 開始時若你的餘額比下注金額少，系統會**以目前餘額為準**下注 |
| 最低下注 | 25 柚子幣 |
| 開始後 | 遊戲一旦開始，就不能再下注或修改 |

> ⚠️ 因為是開局時才扣款，請**確保開局時餘額足夠**，否則實際下注金額會被縮減，甚至變成 0。

## 結算後再開新局

結算畫面下方有三個按鈕：**押閒家（新局）／押莊家（新局）／押和局（新局）**。

- **任何人都可以按**，按的人會成為**新一局的開局者**。
- 按下後會跳出視窗，預設帶入你**上一局的下注金額**（如果你沒玩過就預設 100），可修改。
- 送出後，原本那則訊息會**直接變成新一局的招募大廳**，大家重新下注（不會自動沿用上一局的名單）。
- 按鈕有效時間 **10 分鐘**，冷卻 5 秒。

## 勝率與期望值參考

以下為依本 Bot 實際規則（每局一副新洗的 52 張牌），模擬約 **200 萬局**得到的數據，僅供參考：

| 結果 | 出現機率 |
| --- | --- |
| 莊家贏 | 約 **45.9%** |
| 閒家贏 | 約 **44.7%** |
| 和局 | 約 **9.4%** |

| 下注選項 | 平均每 1 柚子幣的期望損益 |
| --- | --- |
| 押莊家 | 約 −0.010（−1.0%） |
| 押閒家 | 約 −0.013（−1.3%） |
| 押和局 | 約 −0.155（−15.5%） |

**結論**：與所有賭場遊戲一樣，百家樂對玩家長期是負期望值。**押莊家損失最小，押和局風險最高**，請當作娛樂就好。

## 常見問題 FAQ

**Q：我可以不是開局者也玩嗎？**
A：可以。任何人都能在招募期間按按鈕輸入金額加入。

**Q：我下注後反悔了怎麼辦？**
A：遊戲開始前，再按一次任何一個押注按鈕輸入新金額，就會覆蓋舊的下注；遊戲開始後就不能改了。

**Q：開局者離開了，遊戲會卡住嗎？**
A：不會。10 分鐘到期後系統會自動開始遊戲。

**Q：為什麼我押莊家贏了，入帳比押閒家少？**
A：莊家贏要抽 5% 佣金，這是百家樂的標準規則。

**Q：和局的時候我押閒家，錢會不見嗎？**
A：不會，和局時押閒家或莊家的玩家本金都會**退回**。

**Q：莊家／閒家的點數我要自己算嗎？**
A：不用，畫面會顯示雙方點數與最終勝者。

## 新手小提示

- 百家樂純靠運氣，沒有必勝策略，**不要被「路單」、「連莊」之類的說法迷惑**，每一局都是獨立事件。
- 想要少輸一點 → 押莊家；想玩刺激 → 押和局（但要有輸光的心理準備）。
- 開局者按「開始遊戲」前，記得確認**自己與朋友的餘額都足夠**。
